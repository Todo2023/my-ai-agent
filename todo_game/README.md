# トドの晩酌

トドを左右に動かして、**口の色と同じ酒だけ**を飲ませるブラウザゲーム。

```
open todo_game/index.html
```

依存なし・ビルドなしの HTML 1枚（Canvas + WebAudio、画像/音声アセットゼロ）。

## ルール

| | |
| --- | --- |
| 同じ色を飲む | 得点。5杯で「飲みたい色」が変わる |
| ちがう色を飲む | 吐く。残機 −1（残機4でおしまい） |
| 大吟醸（金） | どの色でも飲めるボーナス。50点 |
| 連続で飲む | 5杯ごとに倍率が上がる（最大5倍） |
| 酔い | 飲むほど溜まり、操作が鈍って勝手にふらつく。時間で醒める |

落下速度と出現間隔は得点に応じて上がる。

## 操作

- `← →` / `A D`、またはドラッグ（スマホはタップして指を動かす）
- `Space` / `Enter` / タップ で開始・再開
- 最高得点は `localStorage` に保存

## 実装メモ

- 色だけに情報を載せない。すべての酒に銘柄の一文字（梅／ラ／赤／茶／大）を描画していて、口の中にも同じ字が出る
- `prefers-reduced-motion` のときは画面揺れ・酔いのふらつき・点滅を止める
- 出現する酒の5割は「いま飲みたい色」に寄せている。完全ランダムだと当たりが来ない時間が長すぎて理不尽になるため
