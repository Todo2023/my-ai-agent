# 講座資料の書き方

**中身のテキストだけ書いてください。見た目はこちらで持ちます。**

- 元原稿：`curriculum/lesson-00.md` 〜 `lesson-12.md`（デモ1回＋本編12回の全13回）
- スライドの元：`curriculum/slides_src/lesson-NN.pptx`（**docs/ の外に置いています**。後述）
- 表示用ページ：`docs/lesson-00.html` 〜 と `docs/lessons.html`（**自動で作られます。直接編集しないでください**）
- スライドの画像：`docs/slides/lesson-NN/01.png`〜（**自動で作られます**）

## 手順

1. `curriculum/lesson-01.md` などをメモ帳やVS Codeで開いて、書く
2. 次を実行する

```
uv run curriculum/build.py
```

3. `docs/lessons.html` をブラウザで開いて確認する
4. `git add -A` → `git commit` → `git push`

書けているかだけ確認したいときは `uv run curriculum/build.py --check`（ページは作られません）。

## いちばん上の情報欄

`---` と `---` の間に書きます。**この形は崩さないでください。**

```
---
回: 1
種別: 本編
題: 問いを立てる × AIとの役割分担
日付: 2026-10-01
所要: 60分
ねらい: 手元の問いを1つ、答えが返る形に書き換えられる。
---
```

`日付` と `ねらい` は空でも構いません（行ごと消してください）。

## 本文の書き方

| 書きたいもの | 書き方 |
| --- | --- |
| 見出し | `## この回のねらい` |
| 小見出し | `### 補足` |
| 段落 | そのまま書く。空行で区切る |
| 箇条書き | `- ひとつ` |
| 番号つき | `1. ひとつ` |
| 強調 | `**ここが大事**` |
| 取り消し線 | `~~消したい言葉~~` |
| 引用・投げかけ | `> 今週、答えが出ても何も始まらなかった問いは？` |
| 区切り線 | `---`（行に1つだけ） |

### 添削の前後を見せる

```
:::添削
前: 御社の企業理念に共感しました
後: 入社後、この意思決定に自分の強みをどう使うか
理由: 「共感した」で終わる文章は、誰にでも書ける。
:::
```

`理由:` は書かなくても構いません。赤ペンの取り消し線つきで表示されます。

### 進行表を出す

`|` で区切ります。3つ目は補足で、省略できます。

```
:::進行
0-5分 | この回で何ができるようになるかを言う | 期待値を先に揃える
5-20分 | 3つの基準を実例で説明する | 実例から入る
20-35分 | その場で参加者の問いを書き換える | ここが本体
:::
```

### 表を出す

1行目が見出しになります。

```
:::表
前 | 後 | 欠けていた基準
AIって結局何に使えるの | 自分の意思決定にAIをどう組み込むか | 動く・自分の
:::
```

## 「準備中」と「書けています」

一覧ページには、回ごとに状態が出ます。

- **本文に中身があれば**「書けています」
- **見出しだけ、または `未記入` `未定` `TODO` しか無ければ**「準備中」

見出しだけ並べた状態で「書けています」にはなりません。**一覧の表示が実態とずれないようにしてあります。**

## 公開の範囲とパスワード

資料ページは**受講者限定**です。

- 検索には載りません（`noindex`）
- **LPとは別のパスワード**のゲートに入ります
- **ゲートは表示を隠すだけで、鍵ではありません。** 外に出せない情報は書かないでください

### パスワードが2つある理由

| ゲート | 対象 | 誰に渡すか |
| --- | --- | --- |
| `site` | LP（トップ・料金・FAQなど） | デモ前に中身を見せたい相手 |
| `lesson` | 講座資料（`lessons.html`・`lesson-NN.html`） | **申し込みが済んだ受講者だけ** |

分けている理由は、**トラブルのときに片方だけ直せるようにする**ためです。
資料のパスワードが漏れても、資料側だけ変えればよく、LPを見せている相手に影響しません。

### 受講者がたどる道

トップページ（`index.html`）の下に「**受講中の方：講座資料（全13回）→**」を置いてあります。
URLを個別に案内しなくても、**LPから1本の道でたどり着けます。**
「開けない」と言われたときも、同じ道を一緒にたどれば原因が分かります。

### パスワードを変えるとき

`docs/assets/gate.js` の先頭にある `GATES` の `hash` を差し替えます。**ファイルはこれ1つだけです。**

新しいハッシュの作り方：

```
python -c "import hashlib;print(hashlib.sha256('新しいパスワード'.encode()).hexdigest())"
```

`site` と `lesson` のどちらを変えるかを間違えないでください。

## やってはいけないこと

- `docs/lesson-*.html` と `docs/lessons.html` を直接編集する（次のビルドで消えます）
- 本文にHTMLタグを書く（そのままの文字として表示されます。受講者の画面が壊れないようにするためです）
- `---` の情報欄の形を崩す

## 試験

`uv run --with pytest python -m pytest curriculum/test_build.py -q` で12件走ります。
書式を増やしたいときは、ここに1件足してから直してください。

## 回を増やす・減らす

`curriculum/lesson-NN.md` を足すか消すだけです。**番号は連番でなくても動きます**が、
ファイル名の順に並ぶので、2桁（`lesson-10.md`）で揃えてください。

足したあとは `uv run curriculum/build.py` を実行してください。
一覧の「全◯回」も自動で数え直します。

**消した回の `docs/lesson-NN.html` は自動では消えません。**手で削除してください。

## スライドについて

受講者には**ページの中で読んでもらいます。ファイルは配りません。**
各回のページの上部にスライドが埋め込まれていて、「次 →」ボタンか矢印キーで送れます。

### 元ファイルを docs/ に置かない理由

`docs/` の中身は、そのままWebに出ます。**PowerPointを docs/ に置いた時点で、
URLを知っている人がダウンロードできる状態**になります。
そのため元は `curriculum/slides_src/` に置き、**出来上がった画像だけ**を `docs/` に入れています。

なお、画像そのものは保存できます。**これは「配らない」であって「守る」ではありません。**
外に出せない情報はスライドに載せないでください。

### スライドを差し替えるとき

**この変換はTodoさんのPCでは行いません。**LibreOfficeという別のソフトが要るためです。
差し替えたい `.pptx` を**Claudeに渡してください。**こちらで変換して入れます。

（こちらでの手順：`curriculum/slides_src/` に置いて
`uv run --with pymupdf curriculum/slides.py` → `uv run curriculum/build.py`）
