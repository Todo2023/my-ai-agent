# 音源ファイルの置き場

**ここにファイルを置くだけで、合成した鳴き声のかわりにその音が鳴る。** コードは触らなくてよい。
置いていないものは、これまでどおり合成音のまま。

## ファイル名

| 置くファイル | 何の音 |
| --- | --- |
| `inu.mp3` | いぬ「わんわん」 |
| `neko.mp3` | ねこ「にゃーん」 |
| `buta.mp3` | ぶた「ぶーぶー」 |
| `kuma.mp3` | くま「がおー」 |
| `nezumi.mp3` | ねずみ「ちゅーちゅー」 |
| `chou.mp3` | ちょうちょ（羽ばたき） |
| `saru.mp3` | さる「うっきー」 |
| `hitsuji.mp3` | ひつじ「めえめえ」 |
| `kaeru.mp3` | かえる「けろけろ」 |

拡張子は `.mp3` `.ogg` `.wav` `.m4a` のどれでもよい（この順に探す）。

## 選ぶときの決まり

- **CC0（パブリックドメイン相当）だけ。** 表示義務のあるもの（CC BY）は、
  表示場所を作っていないので使わない
- **1ファイル 1〜3秒、100KB以下**を目安に。圏外用に端末へ抱えるので、
  合計 1MB を超えないようにする
- 音量は大きすぎないもの。幼児が耳元で鳴らす
- 本物の鳴き声は、うなり声など**こわい音**が混じることがある。短く優しいものを選ぶ

拾える場所の例（どれも CC0 の項目を選ぶこと）

- Freesound（ライセンス欄で「Creative Commons 0」に絞る）
- Pixabay の効果音
- OpenGameArt（CC0 のもの）

## 置いたあと

`sw.js` の `ASSETS` に足す必要はない。はじめて鳴らしたときに端末へ入る。
ただし**中身を入れ替えたときは、`index.html` と `sw.js` の `?v=` と
`app.js` の `VERSION` を上げること。** 上げないと古い音が残る。
