# ビジネスタウン（試作）

マッチングの「一覧から探す」を、「街を歩いて出会う」に置き換えた画面。
昔のRPGのように、ドット絵の街を歩いて人に話しかけると、その人のことが分かる。

**https://todo2023.github.io/my-ai-agent/hp/match/town/**

ビルド不要・サーバーなし・外部の読み込みなし。画像ファイルも使っていない
（建物も人も、すべてコードで描いている）。

## 既存のページとの関係

**独立している。** 登録フォーム（`../`）や管理画面（`../admin/`）とは、
CSSもJavaScriptも共有していない。この街を消しても、他は何も壊れない。

## ファイル

| | |
| --- | --- |
| `index.html` | 画面の骨組み |
| `town.css` | 見た目（RPG風の黒枠、十字キーなど） |
| `data.js` | **街の中身。建物と人はここだけ直せば変わる** |
| `town.js` | 地図の組み立て・描画・移動・会話 |

## 操作

| | |
| --- | --- |
| 移動 | 画面の十字キー／キーボードの矢印キー・WASD |
| 話す・調べる | 「はなす」ボタン／Enter・スペース |
| 閉じる | Esc |
| 一覧 | 右上のボタン。歩かずに全員見られる。名前を選ぶとその人の前へ移動する |

歩くのが面倒な人のために、**一覧から直接その人の前まで飛べる**ようにしてある。
街歩きは楽しさのためのもので、そこを通らないと使えない作りにはしていない。

## 街を変える

`data.js` だけ直せばよい。

```js
places: [
  { id:"lab", name:"リサーチセンター", x:2, y:2, w:7, h:5, door:[5,6],
    colors:["#8a93ad","#4a5570","#8fd3ff"],   // [壁, 屋根, 窓]
    about:"…" },
]
```

- `x,y` は左上のマス、`w,h` はマス数、`door` は入口のマス
- 入口は建物の**外側に面した行／列**に置くこと（前に立てないと入れない）
- 人は `x,y` に立たせる。建物の中や、通れないマスには置かない

直したあと、次の3つを自分で確かめる。

1. 出発点（ひろば）から、その人のところまで歩いて行けるか
2. 入口の前に立てるか
3. 人が建物にめり込んでいないか

## 人のデータについて

`people` の項目名は、登録フォームや `profiles` テーブルと**同じ**にしてある。

```
name / organization / title / industry / region /
current_work / strengths / target_profile / purpose_tags
```

あとで Supabase から読み込む形に変えるとき、`data.js` の中身を
差し替えるだけで済む。`tagline`（街で見せる一言）と `x, y, place, color`
だけが、この街のための追加項目。

> ⚠️ **ここに実在の人の情報を書かないこと。**
> このリポジトリは公開されている。いま入っているのは全員架空の人物。
> 本物のデータを扱うときは、Supabase から読む形にしてからにする。

## 「きになる」について

人に話しかけると「きになる」を選べる。これは**その端末の中（localStorage）に
控えるだけ**で、相手には何も届かない。マッチング事務局に行くと、控えた人を確認できる。

連絡するかどうかは、これまでどおり**人が確認してから**決める。
街の画面から直接メッセージが飛ぶことはない。

## 確認したこと

Chromium（スマホ幅390px／PC幅1280px）で確認済み。

- 出発点から、8人全員のところまで歩いて行ける
- 8つの建物すべて、入口の前に立てる
- 建物の壁は通り抜けられない
- 人に話しかけると4ページのプロフィールが出て、「きになる」で控えられる
- 事務局で、控えた人を確認できる
- 一覧から人を選ぶと、その人の前まで移動する
- 横スクロールなし・JSエラーなし
