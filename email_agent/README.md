# email_agent（ゲート1: 動くエージェント）

自然文の指示から宛先・件名・本文を組み立て、メールを自動送信するエージェント。

やっていること:

1. ユーザーの自然文（例:「taro@example.com に明日の会議はリスケになったと伝えて」）をLLMに渡す
2. LLMが宛先・件名・本文を組み立て、`send_email_tool` を呼び出す
3. `mailer.py` の `send_email` が実際のSMTP送信を行う（LLMはここに関与しない）

## セットアップ

```bash
cd email_agent
uv sync
cp .env.example .env
```

`.env` に以下を設定する:

- `GEMINI_API_KEY`: Gemini APIキー
- `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASSWORD` / `FROM_EMAIL`: 送信に使うSMTPアカウント
  （Gmailの場合は通常のパスワードではなく「アプリパスワード」を発行して使う）

### 安全対策: DRY_RUN

デフォルトでは `DRY_RUN=true` になっており、実際にはメールを送信せず、
送信内容（宛先・件名・本文）を標準出力に表示するだけ。

実際に送信するには `.env` で `DRY_RUN=false` に変更する。

送信はいちど実行すると取り消せない操作なので、まずは `DRY_RUN=true` のまま
何度か試して、生成される本文の品質を確認してから無効化することを推奨する。

## 実行

```bash
uv run python agent.py "taro@example.com に、明日の定例会議は木曜15時に変更になったと伝えて"
```

引数を省略するとサンプルの指示で実行される。
