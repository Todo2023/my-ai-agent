FAQ

よくある質問

紹介制度・料金・受講内容についてまとめています。ここに載っていないご質問は、お気軽にお問い合わせください。

ご紹介・お申し込みについて

Q紹介がなくても参加できますか？
A　はい、参加いただけます。ただし紹介がない場合は、お申し込み前に一度簡単なヒアリングをお願いしています。
Q学生であることの証明は必要ですか？
A　既存メンバーからのご紹介の場合は、原則として不要です。ご紹介のない一般のお申し込みでは、学生向け料金のため、学生証などで在籍を確認させていただく場合があります。確認が必要な場合は、お申し込み後にこちらからご案内します。
Q定員はありますか？
A　当面10名程度を想定した少人数運営です。空き状況はお問い合わせ時にご案内します。

受講内容について

Q思考力かAI、どちらか一方だけ受けたいのですが。
A　MEMBER以上は統合コンテンツのため、両方が含まれる形でお届けしています。
Qオフィスアワーはどう予約しますか？
A　予約制で、1回あたり15分程度です。予約方法は入会後にご案内します。

料金・解約について

Qトライアルの内容は薄いのですか？
A　いいえ。学生向けの3プランでは、初月は価格のみを下げており、講義回数・添削・質問対応などの内容は通常月と同じです。高校生向けコースの初月割引は現在調整中です。
QAIツールの利用料は受講料に含まれますか？
A　含まれません。Claude や Claude Code などのAIツールは、各自でご契約いただき、利用料はご自身のご負担となります。基本は無料プランで進められる範囲を扱いますが、回によっては有料プランがあると取り組みやすい内容もあります。その場合は事前にお知らせします。
Q支払い方法は何が使えますか？
A　PayPay（送金）または現金に対応しています。どちらも難しい場合は、お申し込み時にご相談ください。ご事情に合わせて、別の方法を一緒に決めます。
Qいつでも解約できますか？
A　月単位でいつでも可能です。縛りや違約金はありません。

ここにない質問は、直接お問い合わせください。
