# IPROSリード仕分け

IPROSから出した引き合い一覧を、**Pardotに入れる前に**4つに分ける道具。
管理画面から落ちてくる **`.xlsx` をそのまま**開ける（CSVでもよい）。

**https://todo2023.github.io/my-ai-agent/eigyo/lead/**

ビルド不要・サーバーなし・**通信なし**。選んだCSVは端末の外へ出ない。
（`fetch` も `XMLHttpRequest` も書いていない。ブラウザの開発者ツールの
ネットワークタブで確かめられる）

## なぜ要るか

岩田さんの全体フローのうち、**②「Pardot登録（重複・除外チェック）」**にあたる部分。
CSVをそのままインポートすると、

- 既にいる人がもう1件できる（プロスペクトの二重作成）
- 競合他社・代理店がナーチャリング対象に入る
- 同じ人が同じ週に2回DLしていて、2行になっている

が起きる。手作業で毎週これを見るのは無理があるので、機械にやらせる。
**判断は人が、下ごしらえは機械が**、という分け方にしてある。

週次の回し方は [`../../sekkei/ipros-pardot-tejun.md`](../../sekkei/ipros-pardot-tejun.md)。

## 使い方

| | |
| --- | --- |
| 1 | IPROSの管理画面から出したファイルを選ぶ（`.xlsx` そのままでよい。CSVなら Shift_JIS / UTF-8 どちらでも） |
| 2 | Pardotの既存プロスペクト一覧のCSVを選ぶ（任意。無いと全員が「新規」になる） |
| 3 | どの列が会社名・担当者・メール・DL資料・日時かを合わせる（見出しから推測する。次回は覚える） |
| 4 | 除外する会社名を1行1社で書く |
| 5 | 「仕分ける」を押して、出てきた4つのCSVを保存する |

## 出てくるもの

| ファイル | 何 | Pardotで |
| --- | --- | --- |
| `ipros_shinki_*.csv` | 新規インポート用 | プロスペクトを新規作成してよい |
| `ipros_kizon_*.csv` | 既にいる人 | **新規作成しない。**リスト追加だけ |
| `ipros_yusen_*.csv` | **先に営業へ回す** | 上2つから抜き出したもの。ステップメールを待たずに電話・訪問の対象 |
| `ipros_haishin_fuka_*.csv` | **配信不可** | Pardot側でオプトアウト済み。**絶対に入れない** |
| `ipros_jogai_*.csv` | 除外リストに当たった行 | **入れない。**ただし理由つきなので目視する |
| `ipros_fubi_*.csv` | メールが空・形式が不正な行 | **入れない。**IPROS側を確認する |

`ipros_yusen_*.csv` は**別の束ではなく、新規と既存から抜き出した一覧**。
Pardotへの入れ方は変えず、**営業が見る順番だけ**を変えるためのもの。条件は次のどちらか。

- `コメント【至急度】` が「至急」
- `コメント【動機】` が「具体的検討」

どちらもIPROSが付けてくれた値で、**メールを1通も送る前から分かっている**。
Day14のクリックを待つ必要がない層がここに出る。

どのCSVにも `リードソース` 列を足して **`イプロス`** を入れてある。
Pardotの `Source` フィールドで既に使われている表記に合わせたもの（`IPROS` と書くと集計が割れる）。
`動機` `至急度` の2列もそのまま持ち出すので、Pardotにカスタムフィールドを作れば
Engagement Studio の分岐にも使える。
インポート時にカスタムフィールドへ当てれば、あとの流入経路分析で効く。

## IPROSの出力の形（2026-09-07 の実物で確認）

| | |
| --- | --- |
| 形式 | `.xlsx`（「引き合い一覧」） |
| 見出しの位置 | **1行目ではない。**上に検索条件が十数行ならぶ（**いちばん列が埋まっている行**を見出しとみなして自動で読み飛ばす） |
| 列 | 40列。`会社名` `姓` `名` `メールアドレス` `ファイル項目` `引き合い日` `引き合い時刻` `イプロス会員区分` ほか |
| 注意 | **姓と名、日付と時刻が別の列。**このツールがつないで1つにする |

### 実測（IPROS 1,156行 × Pardot 10,032件、2026-09-11）

| | |
| --- | --- |
| 新規インポート用 | **276件** |
| リスト追加のみ（既にいる人） | 236件 |
| **配信不可（オプトアウト）** | **70件** |
| 先に営業へ回す | 87件 |
| 除外（退会15・競合1・代理店17） | 33件 |
| メール不備 | 420件 |
| 同じメールをまとめた | 121行 |

**599人のうち323人はPardotに既にいた。**そのまま入れていたら、
323件の二重プロスペクトと、**70件の「配信停止した人への再配信」**が起きていた。

**メールが無い420件は、ほぼ2023年以前の行。**2025年9月以降の414行は全件メールが入っていた。
この一覧が2005年からの全期間だったのが理由で、**週次で期間を絞って出せばここはほぼゼロになる。**

## 判定の中身

- **メール** … 前後の空白を取り、小文字にして比べる。
  ドット無視やプラス以降の切り落とし**はしない**（別人を同じ人にしてしまうため）
- **会社名** … 「株式会社」「(株)」「Co., Ltd.」、空白、中黒、ハイフンを落として比べる。
  **部分一致**なので、`ニクニ` と書けば `株式会社ニクニ` も `ニクニ商事` も当たる。
  当たりすぎるので、除外の束は必ず目で見る
- **退会済み** … `イプロス会員区分` が「退会済み」の行は除外の束へ。退会した人にステップメールを送らない
- **オプトアウト** … Pardot側の `Opted Out` が立っている人は**配信不可の束**へ。
  ※Pardotの書き出しには `Do Not Email` 列もあるが、**中身が入っているのは `Opted Out` のほう**
- **代理店** … Pardot側の `導入先セグメント` が「代理店パートナー」なら除外の束へ。
  岩田さんが手でやっていた代理店除外は、**向こうが既にタグ付けしている**
- **先に営業へ回す** … 何度も来ている人は、**1回でも「至急」「具体的検討」があればそちらを採る**
- **表の中の重複** … 同じメールが複数行あったら、**日時が新しい行**を残す。
  DL資料は「/」でつないで1行にまとめる（何を見た人か分からなくならないように）
- **日時** … 読めない書式は「古い」扱い。読める行のほうが残る

## 注意

- **出力したCSVをこのリポジトリに置かないこと。** 会社名とメールアドレスが入っている。
  `eigyo/lead/.gitignore` で `*.csv` を弾いてあるが、他の場所に置けば効かない
- 端末に残るのは**除外する会社名**と**列の対応**だけ。CSVの中身は保存していない
- このページは `noindex`。検索には出ない
