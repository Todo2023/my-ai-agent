# 毎日の学習プログラム設計（Ciao Hallo）

目的: 出発（2026/11/9）までの32日間、毎日必ず学習する習慣を作る。1日5分×2言語（イタリア語・オランダ語）。
開始日: 2026/10/8（今日）。期間: 10/8〜11/8。旅行中（11/9〜11/13）は休み。

## 1日のレッスン（言語ごとに約5分）
| 順 | 内容 | 目安 | やること |
|---|---|---|---|
| 1 | 前日の復習 | 1分 | 昨日覚えたフレーズを、日本語を見て声に出し、答えを見て確認。「言えた」「まだ」で自己判定 |
| 2 | 新しいフレーズ | 2〜3分 | 1フレーズずつ「聞く→声に出して2回」。カタカナと日本語を見ながら |
| 3 | 確認クイズ | 1〜2分 | 5問（日→外と外→日を交互）。新規と復習のフレーズから出題 |

- 画面上部に経過時間を表示（目安5:00）。時間で強制終了はしない
- 完了すると、その日・その言語に「完了」が記録される（確認の正解数と所要時間つき）
- 2言語とも完了で「今日のレッスン 2/2」

## 前日の復習のルール（毎日必ず入る）
1. 今日より前で一番新しい「新規学習日」のフレーズを出す（通常は昨日の分）
2. 昨日が未実施だった場合は、最後に学習した日の分を出す
3. 5個に満たないときは、まちがいの多い未習得フレーズで補う（最大8個）
4. 初日だけは復習対象がないため、新規から始まる

## 新規フレーズの出し方
- 並び順（旅行で使う順）: あいさつ → 必須ひとこと → 空港・入国 → 数字 → お金 → レストラン → 交通 → 道案内 → 緊急 → ホテル → 買い物 → 観光 → 時間
- 1日の新規数 = 残り ÷ 出発前日までの残り日数（切り上げ、3〜8個）。初日は164個÷32日で6個
- 遅れた日があっても、残り日数で割り直して自動で増える
- 「覚えた」にしたフレーズは新規から除外
- 当日分は日付ごとに固定（再読み込みしても同じ内容）

## 習得の段階（box 0〜3）
- 新規を終えると 1。復習・クイズで正解すると +1（初回で言えた場合は 2）。3で「習得済み」
- まちがえると 1 に戻り、苦手フレーズ一覧に載る

## チェックとアラート
- 「今日」タブに、言語ごとの完了表示と、32日分のカレンダー（濃い緑=2言語完了、薄い緑=片方、赤=未実施）
- 「やったことにする」で手動チェック（アプリ外で練習した日用）。外すことも可能
- 連続達成日数 = 2言語とも完了した日が続いた日数
- 未実施のアラート（アプリを開いている間）:
  - 今日が未実施のあいだ、全タブの上部にバナー、「今日」タブに赤い点
  - 設定した時刻（12・18・20・21・22時から選択、初期は20時）を過ぎると、バナーが赤くなり、メッセージも1回表示
  - 設定でオフにできる
- できないこと: アプリを閉じている間のスマホ通知（アーティファクトでは出せない）

## データ（localStorage `ciao-hallo-v2` に追加）
- `intro{it,nl}`: フレーズid → 新規学習した日付
- `log{日付:{it:{sec,ok,n,at,manual?},nl:{...}}}`: 完了記録
- `today{it,nl}`: 当日の新規フレーズid（日付つき）
- `remind{on,h}`: お知らせの設定
- 夫婦共有（書き出し／読み込み）の対象外。レッスン記録はそれぞれの端末で持つ
