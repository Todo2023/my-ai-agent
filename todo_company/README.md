# 竹田彩香の脳内マップ

頭の中にあるものを丸にして並べた地図。真ん中に本人がいて、合同会社To doはその中の
いちばん大きな一つ、という形にしてある。丸はドラッグで動かせて、押すと中身と投稿文が開く。
共有された「大谷さんの脳内マップ」と同じ仕様に寄せてある。

**https://todo2023.github.io/my-ai-agent/todo_company/**

## 中身

| | |
| --- | --- |
| `map.data.js` | **地図の中身（`NODES` / `LINKS`）。足すのはここだけ** |
| `_body.html` | ページの骨組み（見出し・凡例・板・索引） |
| `map.css` | 見た目。色は `:root` の変数にまとめてある |
| `map.js` | 力学・描画・パネル・配信 |
| `index.html` | 公開用のページ（自動生成。直接さわらない） |
| `artifact.html` | Artifact に貼る1枚版（自動生成。直接さわらない） |
| `build_artifact.py` | `_body.html` + css + js → 上の2つ |
| `obsidian/` | Obsidian に入れる Markdown（自動生成。直接さわらない） |
| `obsidian_export.py` | `map.data.js` → `obsidian/` |

```bash
python3 build_artifact.py   # ページを直したら実行する
python3 obsidian_export.py  # ノートを作り直す
```

丸を足したり言葉を変えたりするときは、`map.data.js` の `NODES` と `LINKS` を直す。
`r` が丸の大きさ、`cat` が色の種類、`body` が押したときに出る文、`sure` が確かさ、
`post: true` を付けた丸だけ投稿文が作られる。

## 動きの中身

- **力学** … 丸どうしが押し合い、線でつながった丸は引き合う。落ち着いたら止まる（電池のため）
- **札** … 大きい丸から順に、他の札や丸に重ならない場所を探して置く。置けなければ出さない。
  選んだ丸と真ん中の丸だけは必ず出す
- **選ぶ** … 押した丸とその隣だけ明るく残り、線が色づく。何もない所を押すと戻る
- **索引** … 種類ごとの見出し付きで、小さい丸も全部載せる。指以外の入口はここだけなので
- 外部のライブラリは読み込んでいない（通信が塞がれている場所でも動く）
- 動きを減らす設定の端末では、animation を回さず最初から落ち着いた形で出す

## 配信（Facebook / X）

投稿できる丸を押すと、配信先ごとの下書きが出る。タブで切り替えても、書き直した文は
それぞれ別に持っている。

| 配信先 | いまできること | 上限 |
| --- | --- | --- |
| Facebook | コピー → ページを開く → 貼り付け | なし |
| X | **文章を入れた状態で投稿画面がひらく**。あとは投稿を押すだけ | 140文字 |

Xは投稿画面のアドレスに文章を載せられるので、貼り付けが要らない。Facebookは
同じことができないため、開く前に自動でコピーしている。

140文字を超えるとき、Xの下書きは文の途中では切らない。「。」の切れ目まで戻して、
入るところまでを残す（1文目すら入らないときだけ「…」で詰める）。

### 押すだけで飛ぶようにするには

配信先ごとの違いは `map.js` の `CHANNELS` だけに閉じ込めてある。自動投稿にするときも、
触るのは各 channel の `deliver()` 1か所。

ただし **このページにトークンを置いてはいけない**。ページを開いた人全員に読めてしまい、
会社のアカウントを触られる。必要なのは、

1. トークンを預かる置き場（Google Apps Script、Cloud Functions など小さいもので足りる）
2. Facebook: ページアクセストークン（Graph API）
3. X: APIの利用登録とトークン

置き場ができたら、`deliver()` をそこへ POST する形に差し替えれば、このページ側は
そのままで自動配信になる。

## 確かさの印

丸ごとに「どこまで確かな話か」を持たせてある（`sure`）。押すと下に出る。

| 印 | 意味 |
| --- | --- |
| 資料から | もらった資料そのものがもと（いまはAI講座の台本） |
| サイトから | ホームページの文言がもと |
| 直接きいた | やりとりの中で本人から聞いた |
| こちらの補い | 地図を組むためにこちらが置いたもの。**未確認** |

「こちらの補い」が付いている丸は、事実として扱わないこと。違っていたら直す。

## Obsidian に入れる

```bash
python3 obsidian_export.py            # obsidian/ に書き出す
python3 obsidian_export.py ~/保管庫    # 保管庫の中へ直接
```

丸ひとつが1枚のノートになり、線が `[[リンク]]` になる。入口のノート
（`竹田彩香の脳内マップ.md`）から全部たどれる。

frontmatter に **種類・確かさ・出どころ** が入るので、Obsidian 側で
`確かさ/guess` を検索すれば、未確認の丸だけを並べられる。

中身は `map.data.js` だけが持っていて、書き出しは形を変えるだけ。地図とノートが
食い違うことはない。**Obsidian 側で直しても次の書き出しで上書きされる**ので、
直すときは `map.data.js` を直す。

書き出したファイルの名前は `.export-manifest.txt` に控えてある。丸の名前を変えたり
消したりしたときは、前回そこに書いてあって今回作られなかったファイルだけを消す。
**そのため、保管庫に直接書き出しても、自分で作ったノートは消えない。**

## 元にした情報

- 新サイトの文言確認用プレビュー（トップ・事業内容・会社概要・お知らせ・お問い合わせ）
- AI講座の台本（2026-09-04）
- Facebookページのアドレス
- やりとりの中で伺ったこと（お名前・こども教育をやってみたいこと）

オレンジの点線の丸（`cat: 'blank'`）が「まだ埋まっていない」印。待っているものは4種類ある。

| 丸 | 待っているもの |
| --- | --- |
| 仕事のほかに時間を使っていること／いま気になっていること | 本人に聞くこと |
| 誰に届けるか／どんな形で届けるか／いまの4事業のどれを使うか | こども教育の中身を決めること |
| 講座でまだ決まっていないこと | 講座側で決まること（台本の「いま決まっていないこと」5つ） |
| 取引先の顔ぶれ／継続とスポットの割合／忙しくなる月／事業ごとの実際の大きさ | 請求書 |

どれを待っているかは、丸ごとの `waiting` に書いてある。中身が入ったら `cat` を
`blank` から変えて、`body` を書き、必要なら下に丸を足す。

「これから」（`cat: 'next'`、金色）は、やりたいと出ているがまだ始まっていないもの。
いまは **こども（幼児）教育** が入っている。始まったら `cat` を `biz` に移す。

### AI講座

台本（2026-09-04）から23個の丸を入れてある。

- 前提「問いは、深く考えた人にしか立てられない」と、3本の柱
  （前提を疑う／事実と意見を分ける／筋を通す）
- 思考力（奇数回）とAI実践（偶数回）に分けた全12回。回ごとに種別・深める考え方・
  ねらい・出すもの
- 番号のない2回（はじめに・デモ）と、進み方

台本の「出すもの」は原文が途中で切れている箇所があるため、**切れていない部分だけを
使い、続きは補っていない**。台本を直したら、`map.data.js` の該当の丸を直す。

## アプリ一覧には入れていない

ここは PWA ではなく、ただの1枚のページ。manifest も Service Worker も置いていないので、
他のアプリの担当範囲を横取りすることはない。トップの一覧（`../index.html`）はスマホに
入れて使うアプリのための場所なので、このページは載せていない。
