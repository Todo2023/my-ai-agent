# 合同会社To do サイト（デモ版）

複数の事業を並行して見せるための、会社サイトの試作。
ビルド不要・サーバーなし・外部の読み込みなし。スマホから直接編集できる。

**https://todo2023.github.io/my-ai-agent/hp/**

## 構成

会社トップで会社を見せ、事業ごとに専用ページを持つ形。
**事業を足すときは、フォルダを1つ増やすだけ。**

```
hp/
├ index.html          会社トップ（事業一覧・会社概要・問い合わせ）
├ style.css           全ページ共通の見た目
├ app.js              全ページ共通の動き（メニュー・フォーム）
│
├ advisory/index.html 事業1：事業アドバイザリー  ★骨組みのみ
├ seo/index.html      事業2：SEO・広報コンテンツ制作  ◎中身あり
│
└ _template/index.html 事業ページのひな形（コピー元）
```

`style.css` と `app.js` は全ページが共有している。
色を変えたい、問い合わせ先を変えたい、というときは**この2ファイルを1回直せば全ページに効く**。

## 事業を1つ増やす手順

1. `_template/` フォルダをコピーして、名前を変える（英小文字。例：`career/`）
2. コピーした `index.html` の **【 】をすべて置き換える**
3. `index.html`（会社トップ）の事業一覧にある「準備中」の枠を、新しい事業へのリンクに書き換える
4. 使わないセクション（無料オファー、FAQ など）は、まるごと削除してよい

ひな形の中には、どこに何を書くかのコメントが入っている。

## いま公開しても大丈夫か

**まだ。** 全ページ共通で、次の手当てが必要。

| | 場所 | いまの状態 |
| --- | --- | --- |
| 検索避け | 各ページの `<meta name="robots" content="noindex">` | 検索に出ないようにしてある。公開時にこの行を消す |
| デモ告知 | 各ページの `<div class="demo-bar">` | 最上部の黒い帯。公開時に削除。フッターの「このページはデモ版です。」も |
| 問い合わせ先 | `app.js` の `CONTACT_EMAIL` | 空。押しても「デモ版のため送信しません」と出るだけ |
| 導入事例 | `seo/index.html` の「導入事例」 | **中身はダミー**。オレンジの注意書きごと、実績と入れ替えるか削除する |

### ページごとの状態

| | 状態 |
| --- | --- |
| **会社トップ** | 会社概要の `（要記入）` 以外は埋まっている。事業一覧の3枠目は「準備中」の仮置き |
| **`seo/`（SEO・広報コンテンツ制作）** | ひととおり書けている。料金は仮の数字 |
| **`advisory/`（事業アドバイザリー）** | **骨組みだけ**。確かな範囲（代表の経歴と相談テーマ）しか入っていない。進め方・料金は空 |

## 埋めていない項目

`（要記入）` でオレンジ文字にしてある。検索すれば全部見つかる。

- 会社トップ … 設立／所在地／代表社員／連絡先
- `advisory/` … 進め方の2〜3段階目／料金プラン

埋めたら `class="todo"` も外すとオレンジ色が消える。

## 問い合わせフォームの動かし方

サーバーがないので、このままでは送信できない。`app.js` の先頭を直す。

1. **メールアプリに渡す（いちばん簡単）**
   `var CONTACT_EMAIL = "";` にアドレスを入れる。送信ボタンでメールアプリが開き、
   入力内容が本文に入った状態になる。どのページから来たかは件名に入る。
   → 相手が「送信」を押す手間が1回増える。取りこぼしはある。

2. **Googleフォームに置き換える**
   フォーム部分を消して、Googleフォームへのボタンリンクにする。回答がスプレッドシートに貯まる。
   → 見た目が自社サイトから離れる。

3. **フォームサービスを使う（おすすめ）**
   Formspree / Formrun などに `<form>` の送信先を向ける。見た目はこのまま、メールで届く。
   → 無料枠に件数制限がある。

最初の1〜2件が取れるまでは 1 で十分。

## 実名について

**個人名はどのページにも出していない。**

- 制作担当 … 「マーケティング専門スタッフ」
- 代表 … 「BtoBメーカーで営業統括・海外事業・新規事業を担当」

前職の社名も出していない。ここは意図的なので、直すときも崩さないこと。

## 文言を直したいとき

直したい日本語をそのまま検索すれば見つかる。
スマホのGitHubアプリからでも、鉛筆マークで直接編集できる。

push すると1〜2分で反映される。反映されないときはブラウザの再読み込み（下に引っぱる）。

```bash
# パソコンで確認する場合
python3 -m http.server 8000
# → http://localhost:8000/hp/
```
