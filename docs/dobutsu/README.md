# どうぶつ めくり

動物の絵を触ると、その動物が出てくるお話が動きだす。18ひきぶん入っている。

**https://todo2023.github.io/my-ai-agent/dobutsu/**

サインインなしで、だれでも開ける。スマホのホーム画面にも入る。

> 配信元ブランチ（`claude/hp-implementation-xubnv6`）では、このフォルダは
> **`docs/dobutsu/`** に置いてある。配信されるのが `docs/` の中だけのため。
> 直したら、そちらにも同じものを入れないとサイトは変わらない。くわしくは
> [`sekkei/haishin.md`](../sekkei/haishin.md)。

## あそびかた

1. 9つのカードから、見たい動物を触る
2. お話が自動ではじまる（1話 40〜50秒くらい）
3. 画面を触ると止まる／もう一度触ると続く
4. `◀ ▶` で場面を送る、`↺` ではじめから、`←` で一覧へもどる

「よみあげる」を入れておくと、端末の読み上げ機能が文を読む。切ることもできる。
設定は端末に覚えておく（外へは送らない）。

- 読んでいる途中で場面が変わらないように、**言い終わるまで待つ**（最大8秒）
- 見ているあいだは**画面が暗くならない**（対応している端末だけ。対応していなくても見られる）
- ほかの画面に移ると自動で止まる。声も止まる

## なぜ動画ファイルではないのか

**お金をかけないため。**

- 動画を作るには、生成サービスか撮影・編集の手間がいる（どちらも有料になる）
- 18本ぶんの動画ファイルはリポジトリが重くなり、GitHub Pages の転送量も増える

そこで、絵は毎コマ canvas に描いている。声は端末が持っている読み上げ機能を使う。
**追加のファイルも、通信も、契約もいらない。いまの費用はゼロのまま。**

## お話を足す・直す

`stories.js` の配列に1つ足すだけで、一覧のカードも増える。

```js
{
  id: "neko", name: "ねこ", title: "ねこの おはなし",
  color: "#eee2d8",                       // カードの下地の色
  card: (g, t) => A.neko(g, { x: 62, y: 82, s: 1, t }),
  scenes: [
    { sec: 6, bg: "hara", text: "画面に出る文。読み上げもこれを読む。",
      act: (g, p, t) => A.neko(g, { x: 150, y: GROUND, s: 1.2, t, walk: 1 }) },
  ],
}
```

- `sec` … その場面の長さ（秒）
- `p` … その場面の進み具合（0→1）。`mix(60, 250, p)` のように使うと動く
- `t` … 通しの秒数。ゆれや羽ばたきに使う
- 動物は**そのままだと左を向く**。右を向かせるときは `flip: true`

足したり直したりしたら、**[`check.html`](check.html) を開いて ぜんぶ みどりか 確かめる。**
各場面を 頭・まん中・おわりの3回ぶん描いてみて、落ちる場面があればそこに出る。

新しい動物を出すときは、`draw.js` の `A` に描き方を足す。
`begin()` を呼んでから体・頭・目の順に描き、最後に `g.restore()` する。

ファイルを増やしたら `sw.js` の `ASSETS` と `CACHE`（`dobutsu-v2` のように）も直す。
直さないと、前に開いた人の端末で古いままになる。

## つくりの決まり

- 動画・音声のファイルは持たない（費用ゼロを崩さないため）
- 通信しない。アカウントもいらない
- 読み上げが無い端末では、その切り替えを出さずに、文字だけで進む
