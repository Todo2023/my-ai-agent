# 1か月版カリキュラム（案）

本編は月1回×13回、13か月かけて進みます。これを**4週間に圧縮した版**の設計です。
**まだ案です。**料金と受け入れ人数は決まっていません（下の「決めていないこと」参照）。

## 誰に向けるか

| | なぜ短期が要るか |
| --- | --- |
| 企業の研修枠 | 予算が期区切り。13か月は稟議が通らないが、1か月なら通る |
| 長期休暇の学生 | 夏休み・春休みにまとめてやりたい |
| 転職・異動の直前 | 特定の時期までに型を入れたい |

**本編の下位互換ではありません。**扱う内容は同じ13回ぶんです。違うのは間隔だけです。

## 日程（4週間）

週3〜4回。**提出すると次が開く**仕組みはそのままなので、遅れた人はそこで止まります。
止まったまま終わらないよう、**週末に追いつく日を1日ずつ置いてあります。**

| 週 | テーマ | 回 |
| --- | --- | --- |
| 事前 | 約束ごとを読む | はじめに（提出なし） |
| 第1週 | 問いをつくる | 第1回 問いを立てる／第2回 AIとの役割分担／第3回 構造化・仮説構築 |
| 第2週 | 調べる | 第4回 情報収集・要約／第5回 リサーチ設計／第6回 データ整理・分析 |
| 第3週 | 伝える | 第7回 結論から書く・話す／第8回 文章を磨く／第9回 発表・アウトプット |
| 第4週 | 形にする・続ける | 第10回 自動化・ミニ制作／第11回 フィードバック／第12回 型を更新し続ける |

各週の最終日は**追いつく日**。新しい回は出さず、溜まった提出を出す日にあてます。

## 1回あたりの負担

| | |
| --- | --- |
| 資料を読む | 30枚前後・20〜30分 |
| ワーク | 20〜30分（提出は目安300字） |
| 合計 | **1回あたり1時間弱** |

週3回で**週3時間**。4週間で12時間強です。集合研修の2日間ぶんに相当します。

## 本編との違い

| | 本編（13か月） | 1か月版 |
| --- | --- | --- |
| 間隔 | 月1回 | 週3回 |
| 資料 | 同じ | 同じ |
| ワーク | 同じ | 同じ |
| 添削 | 24時間以内 | **同じ。ここは縮めない** |
| オフィスアワー | 予約制 | 予約制（枠は期間中に多めに出す） |
| 型が身につくか | 使う場面を挟みながら | **詰め込みになる。ここが弱点** |

**弱点を隠さないこと。**月1回には、間の1か月で実際に使ってみる時間がある、という価値があります。
1か月版はそれが無いぶん、**終わったあとに自分で使う場面を作らないと消えます。**
第12回のチェックリストが、本編以上に大事になります。

## 仕組みの側でやること

- **`paidThrough` を 12 にする。**支払いの範囲で止まると、週3回のペースが崩れます
- **オフィスアワーの枠を、期間中は週2つ以上出す。**間隔が短いぶん、詰まったときに待てません
- **追いつく日には、こちらから何もしない。**催促はしません。止まるのは本人の事情です

## 運営側の負荷

いちばん重いのは**添削**です。1人あたり13本を4週間で受けます。

| 受講者数 | 期間中の添削本数 | 1日あたり |
| --- | --- | --- |
| 3名 | 39本 | 約1.4本 |
| 5名 | 65本 | 約2.3本 |
| 10名 | 130本 | 約4.6本 |

**同時に受けるのは5名までが上限**だと考えます。10名だと、1日5本近くを24時間以内に返すことになり、
質が落ちるか、約束を破ることになります。**約束を破るほうが損失は大きい**ので、人数で調整します。

## 料金（2026-09-03 決定・仮置き）

| | |
| --- | --- |
| 個人 | **30,000円**（税抜・1か月・13回ぶん） |
| 法人研修 | **要相談** |

**個人の30,000円は仮置きです。**変える可能性があります。

本編（社会人向け PRACTICE）は月9,800円で、13回を13か月かけて進むと127,400円です。
1か月版はそれを4週間に圧縮したもので、**扱う内容は同じ13回ぶん**。
価格は圧縮のぶん下がりますが、**中身が薄いからではありません。**
案内文でここを間違えると、本編のほうが割高に見えて、両方売れなくなります。

法人研修を要相談にしているのは、人数によって1人あたりが変わるためです。
本編の法人料金（1〜4名 10,000円／名・月）と、この1か月版をどう並べるかは、
最初の引き合いが来てから決めます。**先に表を作ると、後から動かせなくなります。**
