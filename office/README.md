# 執務室（デモ版）

**クライアントが開く画面。** 契約したAI担当者が席にいて、そこに仕事を渡す。
「AI人材派遣」の体験（スキル別・入れ替え可・月額）を、そのまま画面にしたもの。

**https://todo2023.github.io/my-ai-agent/office/**

ビルド不要・サーバーなし・外部の読み込みなし。画像ファイルも使っていない
（似顔絵は `app.js` の中でSVGを組み立てている）。

## 社内用の道具とは別もの

| | 誰が見るか | 中身 |
| --- | --- | --- |
| [`office/`](.)（ここ） | **クライアント** | 担当者の顔・できること・料金。仕事を渡す入口 |
| [`../eigyo/`](../eigyo/) | **社内** | 担当者の中身（プロンプト）。調べ方と書き方の制限 |

**この2つは意図的に分けてある。** `office/staff.js` にプロンプトを書かないこと。
クライアントに配る画面に指示文が載ると、そのままコピーして使われる。

担当を1人増やすときは、両方に足すことになる。

| | 足す先 | 何を書くか |
| --- | --- | --- |
| 見せ方 | `office/staff.js` | 役割名、肩書、経歴、できること、できないこと、料金 |
| 中身 | `../eigyo/agents.js` | 調べる先、仮説の立て方、書き方の制限 |

## 画面でできること

昔のRPGと同じ作りにしてある。**部屋を歩いて、担当に話しかける。**

1. **歩く** … 十字キー（パソコンでは矢印キー／W A S D）で1マスずつ
2. **話しかける** … 担当の正面に立って「はなす」（パソコンでは Enter か Space）。
   机は挟んでいてよい。カウンター越しに話す形
3. **仕事を頼む** … 会話から。商談を1件登録すると、その席に積まれる
4. **話を聞く** … プロフィール。**できないことも必ず出す**
5. **担当を入れる／外す** … 空席（椅子だけ置いてある）に話しかけて配属。合わなければ外せる
6. **進み具合を見る** … 受付 → 準備中 → 納品済み

歩くのが難しいときのために、**「一覧で見る」**で従来のカード表示に切り替えられる。
できることは同じ。キーボードだけで操作したい場合もこちら。

## 部屋の作り

| | 何を持っているか |
| --- | --- |
| `room.js` | 部屋の形、ドット絵、歩く動き、話しかける判定 |
| `app.js` | 配属と依頼のデータ、重ねて出す画面、一覧表示 |
| `staff.js` | 担当者の情報（`hello` が話しかけたときの第一声） |

`room.js` は `OFFICE.〜` しか呼ばない。**部屋の見た目を作り直しても `app.js` は触らなくてよい。**

部屋の形を変えるときは `room.js` の `MAP` を書き換える。1文字が1マス。

```
# 壁 ／ D 机 ／ P 観葉植物 ／ = 入口の扉 ／ . 床
```

担当が立つ場所は `SEATS`（`[列, 行]`）、自分の初期位置は `START`。

## 経歴の書き方

`staff.js` の `career` には、**会社名・入社年・部署名を書かない。**

社名を伏せても、入社年と部署名まで揃うと人物が特定され得る。
いまは「大手製薬メーカーのオンコロジー領域で10年」まで落としてある。
`hp/README.md` の「実名について」と同じ考え方。

## ドット絵

`room.js` の `drawPerson()` が、四角を積んで人を描いている。
12×16のドットで、髪・顔・体・腕・足の順。向きと足の動きだけが変わる。
色は `staff.js` の `color` から作っている（自分だけオレンジで、担当と見分けがつくようにしてある）。

**いまの絵は仮。** 見せ方が固まったら描き直す前提。
外部の画像・フォント・3Dは読み込めない（無料構成を保つための決まり）ので、
描き直すときも、この関数の中で四角を積むか、SVG／CSSの範囲で作る。

名札だけはHTMLで置いている（`.labels`）。日本語をドットで描くと読めないため。

## パソコンで確認する場合

```bash
python3 -m http.server 8000
# → http://localhost:8000/office/
```

保存した内容を消したいときは、ブラウザの開発者ツールで `localStorage` を空にする
（キーは `office.v1.seats` と `office.v1.jobs`）。
