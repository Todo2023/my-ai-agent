# トドの晩酌

回転レーンを流れてくる皿の蓋を開けて、ご注文と同じ品ならトドが食べる。
スマホにインストールできる PWA（Android / iPhone どちらも可）。

```
# ローカルで動かす（Service Worker を使うので http で開く）
python3 -m http.server 8000 --directory todo_game
# → http://localhost:8000
```

## スマホに入れる

**https://todo2023.github.io/my-ai-agent/todo_game/** を開いて、

- **Android（Chrome）**: メニュー → 「アプリをインストール」／「ホーム画面に追加」
- **iPhone（Safari）**: 共有 → 「ホーム画面に追加」

どちらもアドレスバーなしの全画面で起動する。一度開けばオフラインでも遊べる（`sw.js` が一式をキャッシュする）。QRは `qr-app.png`。

公開は `main` の `todo_game/` を GitHub Pages がそのまま配信している（リポジトリ直下の別ゲームとは URL もキャッシュも分かれている）。ゲームを直したら `main` の `todo_game/` を更新すれば反映される。無料の範囲で動いていて、サーバも外部APIも使っていない。

## ルール

| | |
| --- | --- |
| 皿の中身 | 蓋の下。開けるまで分からない |
| 手前の明るい皿をタップ | 蓋が開く（`Space` なら正面の皿） |
| ご注文と同じ品 | トドが食べる。ごきげんが回復して得点 |
| ちがう品 | ごきげんが下がる。ただし蓋は開いたまま回り続ける |
| 覚えている皿を出し間違える | 未知の皿を開けるより重い減点 |
| ごきげんが満タン | **満腹**。トドがごろんと転がって +500 点 |
| 特上（金の星） | どの注文でも食べる。250点 |
| ごきげんが尽きる | おあいそ |

ご注文はトドの口の中に出る。あそびかたは初回に実際に触りながら進むチュートリアルで案内する（「あそびかた」ボタンでいつでも見直せる）。

## ファイル

| | |
| --- | --- |
| `index.html` | 本体。PWA の設定はここ |
| `game.css` / `game.js` | 見た目とゲーム本体 |
| `manifest.webmanifest` / `sw.js` | インストールとオフライン |
| `icon-*.png` / `apple-touch-icon.png` | アイコン（`_icon.html` を Canvas で描いて書き出したもの） |
| `_body.html` | `index.html` と `artifact.html` で共有する本文 |
| `artifact.html` | Artifact 用に1枚へ固めたもの。`build_artifact.py` で生成 |

`game.css` / `game.js` / `_body.html` を直したら `python3 todo_game/build_artifact.py` を実行して `artifact.html` を更新する。

## 実装メモ

- **注文は必ずレーンに乗っている品から選ぶ**（`nextOrder`）。無い品を頼まれると探しても見つからず、ごきげんが尽きるだけの詰みになるため
- 未知の皿を開けるのは「探索」なので減点を軽く（−0.04）、一度見た皿を出し間違えるのは「失敗」なので重く（−0.10）した。開けっぱなしの皿が次の注文の資産になり、記憶がそのまま強さになる
- 食べた皿はその場の枠を保ったまま流れ、奥へ回り込んでから蓋つきで戻る。位置を作り直すと皿が一箇所に固まって取りにくくなる
- レーンの速度には上限を置いた。上げ続けると人間には皿をタップできない
- 盤面の高さは `calc((100dvh - var(--chrome)) * 0.64)` でも頭打ちにしてある。縦に収まらないとスマホでスクロールが出るため
- 色だけに情報を載せない。品ごとに Canvas で描いたアイコンがあり、トドの口の中にも同じアイコンが出る
- `prefers-reduced-motion` のときは、のれんの揺れ・回転・点滅を止める
