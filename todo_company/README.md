# 合同会社To do の脳内マップ

会社が何を考え、どこに手を動かしているかを、事業一覧ではなく「頭の中の地図」として並べた1枚。
共有してもらった「大谷さんの脳内マップ」の Todo社版として作った下書き。

**https://todo2023.github.io/my-ai-agent/todo_company/**

## 中身

| | |
| --- | --- |
| `index.html` | 公開用のページ。`map.css` と `map.js` を読み込む |
| `_body.html` | 本文だけを取り出したもの。Artifact 用の材料 |
| `map.css` | 見た目。色は `:root` の変数にまとめてある |
| `map.js` | スクロールに合わせて区画を出す。動きを減らす設定なら何もしない |
| `artifact.html` | Artifact に貼る1枚版（自動生成。直接さわらない） |
| `build_artifact.py` | `_body.html` + `map.css` + `map.js` → `artifact.html` |

本文を直すときは `_body.html` と `index.html` の**両方**を同じ内容にして、
`python3 build_artifact.py` を実行する。

## 元にした情報

- 新サイトの文言確認用プレビュー（事業内容・会社概要・お知らせ・お問い合わせ）

請求書はまだ読んでいない。そのため「まだ白いところ」の4区画は空のまま置いてある。
請求書（発行したぶんの一覧でも可）が入れば、取引先・継続とスポットの割合・繁忙月・
事業ごとの大きさが埋まり、地図の区画も実際の比率に描き直せる。

## アプリ一覧には入れていない

ここは PWA ではなく、ただの1枚のページ。manifest も Service Worker も置いていないので、
他のアプリの担当範囲を横取りすることはない。トップの一覧（`../index.html`）はスマホに
入れて使うアプリのための場所なので、このページは載せていない。
