# ブロック崩し（スマホ用）

HTML 1枚だけで動くブロック崩しです。ビルド不要・ライブラリ不要・通信不要。

## 遊び方

1. 画面をタップしてスタート
2. **指でドラッグしてパドルを左右に動かす**（画面のどこを触ってもOK）
3. ボールを落とさずにブロックを全部壊す
4. 全部壊すと次のレベルへ。ライフは3つ

- 上段のブロックほど高得点
- レベルが上がるとブロックの段が増え、上段は2回当てないと壊れなくなる
- ベストスコアはブラウザに保存されます（`localStorage`）
- 右上の 🔊 で効果音のON/OFF

## 動かす

### いちばん簡単な方法

`index.html` をブラウザで開くだけです。

### スマホの実機で遊ぶ

PC と同じ Wi-Fi につないだ状態で、リポジトリのフォルダで簡易サーバーを立てます。

```bash
python3 -m http.server 8000
# または
npx serve .
```

PC の IP アドレス（`ipconfig` / `ifconfig` で確認）を使って、スマホのブラウザで
`http://<PCのIPアドレス>:8000` を開きます。

### 公開したい場合

GitHub Pages が手軽です。リポジトリの Settings → Pages で、
ブランチを選んで公開すると `https://<ユーザー名>.github.io/my-ai-agent/` で遊べます。

## コードの構成

`index.html` の中で完結しています。JavaScript 部分はこの順番で読むと分かりやすいです。

| ブロック | やっていること |
| --- | --- |
| サイズ・レイアウト | `resize()` / `layout()` — 画面サイズから各パーツの大きさを**すべて相対値で**決める。だから端末を選ばない |
| ゲームの組み立て | `buildBricks()` / `startLevel()` — ブロックの並びとレベル設定 |
| 更新 | `update()` / `stepBall()` — 1フレーム分の移動と当たり判定 |
| 当たり判定 | `hitPaddle()` / `hitBricks()` / `circleHitsRect()` — 円と長方形の判定 |
| 描画 | `draw()` — Canvas に背景・ブロック・パドル・ボールを描く |
| 入力 | Pointer Events — タッチもマウスも同じコードで扱える |
| メインループ | `frame()` — `requestAnimationFrame` で毎フレーム「更新 → 描画」 |

技術的なポイントは2つあります。

- **すり抜け防止**: ボールが速いと1フレームの移動量がブロックの厚みを超えて通過してしまうため、
  移動を細かく刻んで（`steps`）判定しています。
- **跳ね返る角度**: パドルの端に当たるほど鋭い角度で返ります（`hitPaddle()` の `offset`）。
  これがないと単調な往復になってゲームになりません。

## 次にやると面白いこと

手をつけやすい順です。

1. **数値をいじる** — `COLS`、`BASE_ROWS`、`START_LIVES`、`ballSpeed()` の係数。
   まずはここを変えて、難易度がどう変わるか体感するのがおすすめです
2. **アイテムを追加** — ブロックを壊したときに稀に落ちてくるカプセル。
   パドルが伸びる／ボールが増える／スピードダウン など
3. **ブロックの配置をレベルごとに変える** — `buildBricks()` でハート型や市松模様に
4. **エフェクトを足す** — 画面シェイク、コンボ表示、残像
5. **BGMをつける** — 効果音と同じ WebAudio で簡単なループを鳴らす
