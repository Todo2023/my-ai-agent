# ふたりの体重帳（Cloudflare Worker 版）

体重計の写真から数字を読み取る記録アプリを、**Cloudflare Workers** 1ファイルで動かします。
画面・保存・写真の読み取りがすべてこの中に入っているので、置き場所はここ1つだけです。

`diet_gas/`（Apps Script 版）から移してきた理由：Apps Script のウェブアプリは
`script.google.com` 上で動くため、**端末のGoogleアカウントの状態によっては開けない**こと
があります（「現在、ファイルを開くことができません」）。Cloudflare なら Google と無関係に
なるので、どの端末・どのアカウントでも同じように開き、**アプリとしてインストール**できます。

## お金の話（先に）

| | 費用 | カード |
| --- | --- | --- |
| Cloudflare Workers（無料プラン） | 0円 | 不要 |
| Cloudflare KV（記録の保存先） | 0円 | 不要 |
| Gemini API（AI Studio のキー） | 0円 | 不要 |

無料枠の目安：Workers は1日10万リクエスト、KV は1日1,000書き込み。夫婦2人が1日数回使う
用途では桁違いに余裕があります。**Gemini のキーに課金アカウントを紐付けなければ**、
使いすぎても請求ではなく `429` エラーで止まり、アプリは手入力に倒れます。

> 無料枠に送ったデータは、Googleがモデルの改善に使う場合があります。
> 体重計の表示部分だけが写るように撮ってください。

## セットアップ（15分ほど・すべてブラウザ操作）

### 1. Cloudflare の無料アカウントを作る

<https://dash.cloudflare.com/sign-up> でメールアドレスとパスワードのみ。カード登録は不要です。

### 2. Worker を作ってコードを貼る

1. ダッシュボード左の **Compute (Workers)** → **Create** → **Start with Hello World!** → **Deploy**
   - 名前は `futari-taijuu` など（この名前がURLになります）
2. 作成後の画面で **Edit code**（`</>` のアイコン）を開く
3. エディタの中身を全部消し、このフォルダの **`worker.js`** の中身を貼り付ける
4. 右上の **Deploy**

この時点でURL（`https://futari-taijuu.<あなたの名前>.workers.dev`）が発行されます。
まだ開いてもエラーになります（保存先とキーが未設定のため）。

### 3. 記録の保存先（KV）を用意する

1. 左メニューの **Storage & Databases** → **KV** → **Create a namespace**
   - 名前は `taijuu` など
2. Worker の画面に戻り、**Settings** → **Bindings** → **Add** → **KV namespace**
   - **Variable name**（変数名）に **`DIET`** ← この名前でないと動きません
   - KV namespace に、いま作った `taijuu` を選ぶ
3. **Deploy** / **Save**

### 4. Gemini のキーを入れる

1. Worker の **Settings** → **Variables and Secrets** → **Add**
2. Type は **Secret**、名前は **`GEMINI_API_KEY`**、値は
   <https://aistudio.google.com/apikey> で取得したキー
3. 保存 → **Deploy**

任意の変数：

| 変数 | 用途 |
| --- | --- |
| `APP_PIN` | 設定すると合言葉を聞きます。URLを知られても中身を見られたくない場合に |
| `GEMINI_MODEL` | 使うモデル。未設定なら `gemini-3.6-flash` |

### 5. 開いてインストールする

`https://futari-taijuu.<あなたの名前>.workers.dev` をスマホで開き、

- **Android（Chrome）**：⋮ →「アプリをインストール」
- **iPhone（Safari）**：共有 →「ホーム画面に追加」

配偶者の方には、このURLを送るだけです（合言葉を設定した場合はそれも）。

## 使い方

1. 上のタブで「夫／妻」を選ぶ（名前はタップして書き換えられます）
2. **体重計を撮る** → 数秒で体重が欄に入る
3. 数字を確かめて **この内容で記録する**

記録するのは体重だけです（体脂肪率は扱いません）。読み取らせる数字を1つに絞ったぶん、
写真から取り違える余地も減っています。

同じ日にもう一度記録すると上書きされます（朝と夜で撮り直しても二重になりません）。

## 設計の考え方

`diet_agent/README.md` と同じです。要点は2つ。

**読み取りはLLM、採否は決定的な処理。** Geminiが返した値は必ず `validate()` を通します。

| ルール | 挙動 |
| --- | --- |
| 20〜250kg の外 | 採用せず「手で入れてください」 |
| `624` のように小数点が落ちた形 | `62.4` に直し、**直したことを画面に残す** |
| 前回から3kg以上の変化 | **値は捨てず**、読み違いの可能性として確認を促す |
| モデルの自信が0.6未満 | 確認を促す |

**保存の前に必ず人間を挟む。** `/api/read` は読むだけで、KVには何も書きません。
書き込むのは、人が数字を見て「記録する」を押して `/api/record` が呼ばれたときだけです。

## テスト

```bash
node test_worker.mjs
```

Cloudflare にも Gemini にも接続しません。KV と Gemini の応答を差し替えて、
保存・上書き・範囲チェック・小数点の補正といった判断だけを確かめます。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| `保存先（KV の DIET）が設定されていません` | 手順3のバインディングの変数名が `DIET` になっているか確認 |
| `GEMINI_API_KEY が設定されていません` | 手順4のシークレット名を確認（大文字・アンダースコア） |
| `モデル … が使えません`（404） | 変数 `GEMINI_MODEL` に使えるモデル名を設定 |
| `混み合っています`（429） | Gemini 無料枠のレート制限。少し待つか、その回は手入力 |
| 記録が消えた | KV のバインディングを別の名前空間に付け替えると、別の保存先を見にいきます |

## ファイル

| ファイル | 役割 |
| --- | --- |
| `worker.js` | これ1つで全部（画面・API・KVへの保存・Gemini呼び出し・PWAの設定） |
| `test_worker.mjs` | 判断ロジックの確認（`node test_worker.mjs`） |

> `worker.js` の下半分（`const PAGE = ...` 以降）は画面のHTMLです。手で編集せず、
> 上半分のロジックだけを読めば構造が分かります。
