# のりもの ぶーん

画面のどこでもさわると、扉がひらいて**のりもの**が出てくる。
出ているのりものをさわると、**クラクションが鳴って車体がゆれる**。外をさわると隠れる。
**まちがいも、終わりも、点数もない。** 0〜2歳向け。

`baa/`（いないいないばあ）と同じ作りののりもの版。動物のかわりに9台が出る。

| ボタン | どこ | 何 |
| --- | --- | --- |
| 🥁 / 🙈 | 左上 | **おとモード**。ボタンをたたくと、そののりものが大きく出て走る |
| 🐾 | 右下 | **みつけた**。会ったのりものが色つきになる |
| ♪ / × | 右上 | 音の入切。**長押し（0.7秒）** |
| 🎹 | 左下 | **音いろ**。オルゴール→もっきん→ピアノ→ふえ→ギター |

**曲は9つとも自作。** のりものの動きに合わせて、走る曲は刻みを細かく、
はたらく車は重く、ロケットは跳ね上がる音程と付点のリズムにしてある。
既存の曲（映画音楽など）は著作権が生きているため使わない。

**ひこうきとロケットは地面に立たない。** お友達として出るときも空にいる。


## 音の作り

音源ファイルは1つも持たない。サイレンやエンジンは、**音の高さを行き来させて**作る
（`playSfx()`）。曲は倍音を重ねた5つの音いろで鳴らす（`INSTRUMENTS`）。
だから圏外でも、どの端末でも同じ音が出る。

## 幼児向けにしていること

- 当たり判定は画面ぜんぶ。指1本しか使えない前提
- **点滅させない**。屋根のランプもゆっくり明滅させるだけ
- 拡大・引っぱり更新・長押しメニューを止めてある
- 音が出せない端末でも遊べる。**音の有無で、絵の長さは変わらない**
- ボタンは小さく端に。音の入切は長押し

## 圏外で遊ぶには

一度ひらけば、あとは機内モードでも動く（Service Worker が全ファイルを抱える）。

1. 電波のあるところで一度ひらく
2. ブラウザのメニューから「ホーム画面に追加」
3. 以降はアイコンから起動。通信は要らない

**中身を変えたら、`index.html` と `sw.js` の `?v=` と `VERSION` を一緒に上げること。**
上げないと、端末が古いファイルを掴んだままになる。
いま動いている版は「みつけた」（🐾）の下に出る。
