# Someday（提案版）

合同会社To do の「つくる部門」のサイト。アプリ・音楽など、創造性側の新事業用。
HTML1枚・ビルド不要・サーバーなし・外部の読み込みなし。

**https://todo2023.github.io/my-ai-agent/someday/**

## 本体サイトとの関係

| | |
| --- | --- |
| **合同会社To do**（本体） | todo-llc.netlify.app。手堅い事業（アドバイザリー／COO代行／SEO／業界アドバイザリー）。代表の実名と経歴で信用を取る作り |
| **Someday**（これ） | 創造性側。アプリ・音楽・試作。実名を前に出さず、**作ったものそのもの**で信用を取る作り |

指示どおり**完全に別ブランド**にしてある。ロゴ・色・書体・語り口すべて別。
ただしフッターと「運営」セクションで運営会社を明記し、本体サイトへリンクしている。

## ブランド名は仮

**「Someday」は提案です。** 決めたら差し替えてください。

由来：To do リストに載せた「やること」に対して、Someday は「いつかやること」。
GTDで言う Someday/Maybe リスト。本体と対になり、かつ独立して成立する名前として選んだ。

ロゴも同じ考え方で、**チェックの入っていない箱**にしてある（本体のロゴはチェックマーク2本）。

差し替えるときは `index.html` 内の `Someday` を全置換。ロゴは `<svg>` が2か所（ヘッダーとフッター）。

## いま公開しても大丈夫か

**まだ。** 3点。

| | 場所 | いまの状態 |
| --- | --- | --- |
| ブランド名 | ファイル全体 | 仮の名前。決定が必要 |
| 検索避け | `<meta name="robots" content="noindex">` | 検索に出ない。公開時にこの行を消す |
| 提案中の告知 | `<div class="note-bar">` | 最上部の黄緑の帯。公開時に削除。フッターの「このページは提案版です。」も |

## 載せているもの

**すべて実在し、実際に動く。** ダミーは1つもない。リンク先はこのリポジトリのアプリ。

| | |
| --- | --- |

### 音楽

**実績がないので、空けてある。** 「Coming」の紫の枠に「まだ公開できるものがない」と明記した。
「依頼できること」の音楽カードにも「これから立ち上げる領域です。実績はまだありません」と入れてある。

1本目ができたら、この2か所を書き換える。

## 設計の意図

本体サイトは「代表が誰か」で信用を取っている。こちらは実名を出さず、
**触れるものが4本ある**ことで信用を取る作りにした。だから：

- ヒーローのすぐ下に「公開中 アプリ4本／登録なし／端末の中だけ」の帯を置いた
- 「つくったもの」を上のほうに置き、画面写真ではなく実物へのリンクにした
- 「つくりかた」で、なぜ早いかを3点に絞って説明した（AIで先に動くものを作る／小さく作る／サーバーを持たない）

料金は載せていない。案件ごとに幅が大きく、仮の数字を置くと縛りになるため。
代わりに「目安：2〜6週間」のように期間だけ出してある。
