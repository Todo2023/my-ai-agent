# ブロック崩し（スマホ用）

HTML 1枚だけで動くブロック崩しです。ビルド不要・ライブラリ不要・通信不要。

## 遊び方

1. 画面をタップしてスタート
2. **指でドラッグしてパドルを左右に動かす**（画面のどこを触ってもOK）
3. ボールを落とさずにブロックを全部壊す
4. 全部壊すと次のレベルへ。ライフは3つ

- 上段のブロックほど高得点
- レベルが上がるとブロックの段が増え、上段は2回当てないと壊れなくなる
- ベストスコアはブラウザに保存されます（`localStorage`）
- 右上の 🔊 で効果音のON/OFF

## 動かす

### いちばん簡単な方法

`breakout/index.html` をブラウザで開くだけです。

### スマホの実機で遊ぶ

PC と同じ Wi-Fi につないだ状態で、リポジトリのフォルダで簡易サーバーを立てます。

```bash
python3 -m http.server 8000 --directory breakout
# または
npx serve .
```

PC の IP アドレス（`ipconfig` / `ifconfig` で確認）を使って、スマホのブラウザで
`http://<PCのIPアドレス>:8000` を開きます。

## 他の人に共有する（GitHub Pages）

このリポジトリは public なので、GitHub Pages を有効にすれば
**URL を送るだけで誰でもスマホから遊べます**。サーバー代も申し込みも不要です。

### 手順（1回だけ）

1. https://github.com/Todo2023/my-ai-agent/settings/pages を開く
2. **Source** で `Deploy from a branch` を選ぶ
3. **Branch** に `claude/simple-game-creation-0zhi4z`、フォルダは `/ (root)` を選んで **Save**
4. 1〜2分待つと公開される

公開URL: **https://todo2023.github.io/my-ai-agent/breakout/**

この URL を LINE やメールで送れば、相手はアプリのインストールなしにブラウザで遊べます。
`qr.png` を見せれば、相手はカメラで読み取るだけで開けます。

## アプリとして入れる（インストール）

App Store や Google Play には出しません。**ブラウザから直接インストールします**（PWA）。
入れてしまえば見た目も使い勝手も普通のアプリと変わりません。

### 画面の流れ

```
QR / URL  →  index.html（インストール画面）  →  ホーム画面にアイコン
                     │                              │
                     └─「そのまま遊ぶ」─→ game.html ←┘ 起動すると直接ここへ
```

QRやURLから開くと、まず**インストール画面**が出ます。端末を見分けて出し分けています。

| 端末 | 表示 |
| --- | --- |
| Android / デスクトップ Chrome | **「アプリをインストール」ボタン**。押すとOSのインストールダイアログが出ます |
| iPhone (Safari) | 「ホーム画面に追加」の手順を4ステップで案内（iOSにはインストールAPIが無いため） |
| iPhone (Safari以外) | Safari で開き直すよう案内。iOSではSafariしか追加できません |
| その他 | インストールなしで遊ぶよう案内 |

どの端末でも、下の「ブラウザでそのまま遊ぶ」からインストールせずに遊べます。

インストール済みのアイコンから起動した場合は、インストール画面は出ずに
**直接ゲームが立ち上がります**（`manifest.webmanifest` の `start_url` が `game.html`、
加えて `index.html` 側でも起動モードを見て転送しています）。

入れると、こうなります。

| | |
| --- | --- |
| アイコン | ホーム画面に他のアプリと並びます |
| 起動 | アドレスバーなしの全画面。ブラウザを開いた感じがしません |
| **オフライン** | **機内モード・圏外でも起動して遊べます**（`sw.js` が一式をキャッシュ） |
| 容量 | 100KB 程度。ほぼ場所を取りません |
| 更新 | このブランチに push すると、次にオンラインで開いたときに自動で新しくなります |

インストールせずに URL のまま遊んでも、ゲーム内容は同じです。

### 更新が反映されないときは

`sw.js` がキャッシュを持っているためです。ファイルを変更したら
`sw.js` 冒頭の `CACHE = 'breakout-v1'` の版数を上げてください（`v2`, `v3`, …）。
古いキャッシュは自動で削除されます。

### 更新したいとき

このブランチに push すれば、1〜2分で公開中のページに反映されます。

> **メモ**: Pages の公開元を `claude/simple-game-creation-0zhi4z` のような作業ブランチに
> 置いたままだと後で分かりにくくなります。落ち着いたら `main` ブランチを作ってそこへ移し、
> Settings → Pages の Branch を `main` に切り替えるのがおすすめです。


## 置き場所について

このゲームの実体は `breakout/` の中にある。ただし **`manifest.webmanifest` だけはリポジトリ直下**に置いてある。
すでにホーム画面に入っている端末は、その URL のマニフェストを見に来るため。
中身の `start_url` / `scope` を `breakout/` に向けてあるので、端末側は自動でこちらへ移る。
直下の `game.html` は、移り終わるまでのあいだ旧アイコンを受け止める転送ページ。

**直下にアプリを置いてはいけない。** 担当範囲（scope）がサイト全体に広がり、
Android では `meshi/` など下の階層のアプリのリンクまでこのアプリが横取りして開いてしまう。
アプリは1つずつフォルダに分ける。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | **インストール画面**。QRやURLから最初に開くページ |
| `game.html` | **ゲーム本体**。HTML・CSS・JavaScript がすべてこの1枚に入っています |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面設定 |
| `sw.js` | オフラインで起動するためのキャッシュ（Service Worker） |
| `icon-180/192/512.png` | ホーム画面用アイコン |
| `qr.png` | 公開URLのQRコード（スマホで開くとき・人に見せるとき用） |

## コードの構成

ゲームのロジックは `index.html` の中で完結しています。JavaScript 部分はこの順番で読むと分かりやすいです。

| ブロック | やっていること |
| --- | --- |
| サイズ・レイアウト | `resize()` / `layout()` — 画面サイズから各パーツの大きさを**すべて相対値で**決める。だから端末を選ばない |
| ゲームの組み立て | `buildBricks()` / `startLevel()` — ブロックの並びとレベル設定 |
| 更新 | `update()` / `stepBall()` — 1フレーム分の移動と当たり判定 |
| 当たり判定 | `hitPaddle()` / `hitBricks()` / `circleHitsRect()` — 円と長方形の判定 |
| 描画 | `draw()` — Canvas に背景・ブロック・パドル・ボールを描く |
| 入力 | Pointer Events — タッチもマウスも同じコードで扱える |
| メインループ | `frame()` — `requestAnimationFrame` で毎フレーム「更新 → 描画」 |

技術的なポイントは2つあります。

- **すり抜け防止**: ボールが速いと1フレームの移動量がブロックの厚みを超えて通過してしまうため、
  移動を細かく刻んで（`steps`）判定しています。
- **跳ね返る角度**: パドルの端に当たるほど鋭い角度で返ります（`hitPaddle()` の `offset`）。
  これがないと単調な往復になってゲームになりません。

## 次にやると面白いこと

手をつけやすい順です。

1. **数値をいじる** — `COLS`、`BASE_ROWS`、`START_LIVES`、`ballSpeed()` の係数。
   まずはここを変えて、難易度がどう変わるか体感するのがおすすめです
2. **アイテムを追加** — ブロックを壊したときに稀に落ちてくるカプセル。
   パドルが伸びる／ボールが増える／スピードダウン など
3. **ブロックの配置をレベルごとに変える** — `buildBricks()` でハート型や市松模様に
4. **エフェクトを足す** — 画面シェイク、コンボ表示、残像
5. **BGMをつける** — 効果音と同じ WebAudio で簡単なループを鳴らす
