# Ciao Hallo 設計メモ（Claude Code 引き継ぎ用）

旅行中に必要な情報（イタリア語・オランダ語・タイ語のフレーズ、翻訳、地図、時計と天気、緊急連絡先）を1つにまとめたアプリ。
旅行日: 2026/11/9〜11/13（イタリア・オランダ、タイと香港は空港経由）。利用者は日本語話者で、現地語は初心者。

## 現在の実装
- 単一ファイル `ciao-hallo.html`（HTML/CSS/JS）。外部に頼るのは Google Fonts、Google マップ（埋め込みとリンク）、Open-Meteo（天気）、MyMemory（翻訳）
- 保存先: `localStorage`（キー `ciao-hallo-v3`、天気は `ciao-hallo-weather`）。端末ごとに独立し、共有はしない
- 公開: Claude のアーティファクト（`downloads` 機能のみ使用）
- ホーム画面版（PWA）: `index.html`（自動生成）＋ `manifest.webmanifest` ＋ `sw.js` ＋ アイコンを GitHub Pages で配信。専用アイコンでインストールでき、一度開けば通信なしでも動く。アーティファクトは `<head>` を持てず manifest を置けないため、この形にしている
  - 編集するのは `ciao-hallo.html` だけ。変更後に `python3 hallo-app/build_pwa.py` で `index.html` とアイコンを作り直す
  - アイコンを変えたら `sw.js` の `VERSION` を上げる
  - 置き場所は `hallo-app/`（2026-10-08 に `ciao_hallo/` から移動。Chrome が古いインストールの記録を持ったままで開けなくなったため、別の場所にして入れ直せるようにした。`ciao_hallo/index.html` は移動先への案内だけ）
  - 保存先はURLごとに別（アーティファクト版とホーム画面版で記録は共有されない）
  - 通信なし対応（2026-11-08）: Service Worker はページを通信優先で取りに行くが、2.5秒で返事がなければ保存済みを出す（海外の弱い電波で止まらないように）。初回に読み込んだフォントもページ側から保存する。読み上げは端末内の音声を優先して選ぶ
  - 「今日」タブに「通信なしで使う準備」: アプリ本体の保存状況、伊・蘭の音声の有無と「試しに聞く」、音声データの入れ方（Android／iPhone）、地図はGoogleマップのオフラインマップで備える案内。音声が通信なしで鳴るかはアプリからは判定できないため、機内モードで試すよう案内している

## データ設計
フレーズ1件 = `[id, 日本語, 伊, 伊カナ, 蘭, 蘭カナ, 泰, 泰カナ]`。現地のヒントは `NOTE[id][言語]`。
- タイ語の `{p}`（平叙）`{q}`（疑問）は丁寧の語尾。フレーズタブの「女性（カー）／男性（クラップ）」で ค่ะ・คะ／ครับ に置き換える
- 保存先: `localStorage` の `ciao-hallo-v3`（lang, gender, fav, places, memo, mapQ, tr）。天気は `ciao-hallo-weather`。旧版の `ciao-hallo-v2` は読まない
- 外部に送るのは、翻訳する文（MyMemory へ）と5地点の緯度経度（Open-Meteo へ）だけ。メモや場所は端末から出ない
