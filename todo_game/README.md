# トドの晩酌

矢印つきの品ブロックを盤面から押し出して、口の絵が合うトドに食べさせるパズル。

```
open todo_game/index.html
```

依存なし・ビルドなしの HTML 1枚（Canvas + WebAudio、画像/音声アセットゼロ）。

## ルール

| | |
| --- | --- |
| 品をタップ | 矢印の向きへ滑る。盤の外まで抜けられれば場から消える |
| 進路が塞がっている | 動かない（揺れるだけ）。押し出す順番がパズル |
| 外に出た品 | 口の絵が合うトドが食べる。1匹あたり3品でお腹いっぱい |
| 食べ手がいない品 | 待ちの棚（6枠）へ。棚が溢れたら **おあいそ** |
| トドが満腹 | 潜って別の品を欲しがるトドが浮上。棚の同じ品はその場で片付く |
| 盤面を全部出す | 完飲ボーナス +200 点、次の軒へ |

軒（ステージ）が進むとブロック数と品数が増える。品は ビール／ラムネ／寿司／肉／枝豆／葡萄 の6種。

## 操作

- 品をタップ・クリック
- 矢印キーで選択して `Enter` / `Space`
- 最高得点は `localStorage` に保存

## 実装メモ

- **必ず解ける盤面の作り方**: 空の盤に1個ずつ置き、「そのとき既に置いてある品を避けて盤外へ出られる向き」だけを矢印に採用する。置いた逆順に外していけば必ず全部出せる（`buildStage` / `pathClear`）
- 色だけに情報を載せない。品ごとに Canvas で描いたアイコンがあり、トドの口にも同じアイコンが出る
- 新しいトドが浮上したとき、棚に溜まった同じ品を時間差で片付ける（`drainShelf`）。詰みかけからの巻き返しが起きる
- 難度は「トドの数 / 棚の枠 / 同時に出る品数」で決まる。先読みなしの自動プレイで 3〜5 軒目に落ちる設定にしてある（`TODO_SLOTS=4` / `SHELF_MAX=6` / `paletteFor`）
- `prefers-reduced-motion` のときは点滅と揺れを止める
