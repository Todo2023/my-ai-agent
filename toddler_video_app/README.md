# わんわん るーれっと（幼児向け どうがアプリ）

ルーレットを回すと、選ばれた動画（YouTube の無料動画）がそのまま再生される、
幼児がひとりでも操作できるシンプルな Web アプリです。

- **ルーレット式**：まんなかの「まわす」を押すと回って止まり、止まったマスの動画が始まります
- **自分で選べる**：マスを直接タップすれば、その動画をすぐ再生できます
- **わんわん中心**：わんわん（いないいないばあっ！）のルーレットが初期表示で、
  **はるちゃんが出てくる回**を優先してマスに並べ、さらに当たりやすく重みづけしています
- **YouTube のUIを触らせない**：プレイヤーの上にフタをかぶせ、操作は下の大きなボタン3つだけ
- **見守りタイマー**：既定20分で「おしまい」画面になり、解除は大人の長押し（1.5秒）

## 使いかた

ローカルサーバーで開きます（`file://` だと YouTube プレイヤーが動かないことがあります）。

```bash
cd toddler_video_app
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

スマホやタブレットで使う場合は、同じ Wi-Fi から `http://<PCのIP>:8000` を開き、
ホーム画面に追加すると全画面で使えます。

## 動画の入れかえ

`videos.js` だけを編集します。

```js
{ id: '0oc7_yryqYQ', short: 'わ〜お', emoji: '🙌', haru: true, title: 'メモ' }
```

| 項目 | 意味 |
| --- | --- |
| `id` | `https://www.youtube.com/watch?v=XXXXXXXXXXX` の `XXXXXXXXXXX` |
| `short` | ルーレットのマスに出る短い名前（3〜6文字くらい） |
| `emoji` | マスに出る絵 |
| `haru` | はるちゃんが出る回は `true`（ルーレットで当たりやすくなる） |
| `title` | 画面には出ないメモ |

設定は同じファイルの `APP_CONFIG` にあります。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `sessionMinutes` | `20` | 続けて見られる時間（分）。`0` で無制限 |
| `autoPlayNext` | `true` | 1本終わったら次を自動再生 |
| `wheelSlots` | `8` | ルーレットのマス数 |
| `haruWeight` | `3` | はるちゃん回の当たりやすさ（倍率） |

## 注意

- 埋め込みが許可されていない動画は再生できません。その場合はアプリが自動で次の動画に
  スキップするので、気づいたら `videos.js` から削除してください。
- 動画IDは公開時点のものです。動画が非公開・削除されると再生できなくなるため、
  ときどき見直してください。
- 音声つき自動再生はブラウザの制限で、必ず画面のタップ（＝ルーレットの操作）を起点にしています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（ホーム／再生／おしまい） |
| `style.css` | 見た目 |
| `app.js` | ルーレットの描画・抽選・YouTube プレイヤー制御 |
| `videos.js` | 動画リストと設定（普段さわるのはここだけ） |
