# 合同会社To do｜新規事業HP（デモ版）

新規事業「SEO・オウンドメディア運用支援／広報・資料作成代行」の**ホームページ試作**。
1ページ完結・HTML1枚。ビルド不要、外部の読み込みなし。

**https://todo2023.github.io/my-ai-agent/hp/**

スマホでそのまま見られる。ホーム画面に入れる必要はない（PWAではないので manifest も Service Worker も持たない）。

## いま公開しても大丈夫か

**まだ。** 3つだけ手当てが必要。

| | 場所 | いまの状態 |
| --- | --- | --- |
| 検索避け | `<meta name="robots" content="noindex">` | 検索に出ないようにしてある。公開するときにこの1行を消す |
| 導入事例 | 「導入事例」セクション | **中身はダミー**。オレンジの注意書きごと、実績と入れ替えるか削除する |
| 問い合わせ先 | `CONTACT_EMAIL`（`<script>` の先頭） | 空。いまは送信ボタンを押しても「デモ版のため送信しません」と出るだけ |

「デモ版」と書いた黒い帯が最上部と最下部に出る。公開時は `<div class="demo-bar">` と、
フッターの `｜ このページはデモ版です。` を消す。

## 埋めていない項目

会社概要の表に `（要記入）` がオレンジ文字で残してある。

- 設立
- 所在地
- 代表社員
- 連絡先（問い合わせ用メールアドレス）

検索すると `（要記入）` で全部見つかる。埋めたら `class="todo"` も外すとオレンジ色が消える。

## 問い合わせフォームの動かし方

サーバーがないので、フォームはこのままでは送信できない。3つの選び方がある。

1. **メールアプリに渡す（いちばん簡単）**
   `<script>` 冒頭の `var CONTACT_EMAIL = "";` にアドレスを入れる。
   送信ボタンでメールアプリが開き、入力内容が本文に入った状態になる。
   → 相手が「送信」を押す手間が1回増える。取りこぼしはある。

2. **Googleフォームに置き換える**
   フォーム部分を消して、Googleフォームへのボタンリンクにする。無料で、回答がスプレッドシートに貯まる。
   → 見た目が自社サイトから離れる。

3. **フォームサービスを使う（おすすめ）**
   Formspree / Formrun などに `<form>` の送信先を向ける。見た目はこのまま、メールで届く。
   → 無料枠に件数制限がある。

最初の1〜2件が取れるまでは 1 で十分。

## 中身の構成

上から順に、BtoBのサービスサイトでよくある並びにしてある。

1. **ヒーロー** — 「御社の強みを、検索で見つけてもらえる記事に変えます。」＋ 月3本／5万円〜
2. **課題** — 「記事を出しているのに問い合わせが増えない」6項目
3. **サービス** — SEO運用支援／広報・資料作成の2本立て
4. **選ばれる理由** — 事業視点でテーマを決める／専門スタッフが書く／少人数で速い
5. **無料サイト診断** — 壁打ちで決めた集客の入口。4ステップ
6. **料金** — ライト5万・スタンダード10万・スポット10万〜
7. **ご依頼の流れ** — 診断から運用まで5段階
8. **導入事例** — ★ダミー
9. **よくあるご質問** — 6問（「AIで書いた記事が来るのでは」への回答を含む）
10. **会社概要**
11. **お問い合わせ**

個人名は一切出していない。制作担当は「マーケティング専門スタッフ」、
代表は「BtoBメーカーで営業統括・海外事業・新規事業を担当」という書き方にしてある。

## 文言を直したいとき

`index.html` 1枚だけ。スマホのGitHubアプリからでも、鉛筆マークで直接編集できる。
直したい日本語をそのまま検索すれば見つかる。CSSとJavaScriptも同じファイルの中にある。

push すると1〜2分で反映される。反映されないときはブラウザの再読み込み（下に引っぱる）。

```bash
# パソコンで確認する場合
python3 -m http.server 8000
# → http://localhost:8000/hp/
```
