# tools/

## topics_inbox.py — AI Topics の候補を集める

毎日 06:10（JST）に GitHub Actions が動いて、`topics-inbox.json` を更新します。
**このファイルは配信していません**（`docs/` の外にあります）。

### 使い方

```
python tools/topics_inbox.py --show
```

いま溜まっている候補が読めます。GitHubの画面で `topics-inbox.json` を
開いても同じです。

### 1本を載せるまでの流れ

1. 候補を読んで、**1本選ぶ**
2. `docs/topics.json` に足す。書くのは次の4つ
   - `title` … 見出し（言い換えて構いません）
   - `lead` … 何が起きたか。**数字には出典を添える**
   - `why` … **なぜ取り上げたか。**講座のどの回とつながるか
   - `questions` … そこから立てられる問い、2つ
3. `tag` は 教育 / 仕事観 / 制度 / 技術 / 調査 / 事例 から選ぶ
   （知らない種別を書いても、色は自動で付きます）

**2と3は人がやります。**ここが講座の中身とつながる部分で、
機械に書かせると、いま読まれている「なぜ取り上げたか」の質が落ちます。

### 記事を画面から消したいとき

その記事のかたまりに `"hidden": true` を1行足してください。

```json
{
  "id": "...",
  "hidden": true,
  ...
}
```

消すのではなく隠す形にしてあるのは、**あとで戻せる**ようにするためです。
