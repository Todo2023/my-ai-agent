# 辰巳彩香の脳内マップ

頭の中にあるものを丸にして並べた地図。真ん中に本人がいて、合同会社To doはその中の
いちばん大きな一つ、という形にしてある。丸はドラッグで動かせて、押すと中身と投稿文が開く。
共有された「大谷さんの脳内マップ」と同じ仕様に寄せてある。

**https://todo2023.github.io/my-ai-agent/todo_company/**

## 中身

| | |
| --- | --- |
| `_body.html` | 本文。**中身を直すのはここだけ** |
| `map.css` | 見た目。色は `:root` の変数にまとめてある |
| `map.js` | 地図の中身（`NODES` / `LINKS`）と、力学・描画・投稿文 |
| `index.html` | 公開用のページ（自動生成。直接さわらない） |
| `artifact.html` | Artifact に貼る1枚版（自動生成。直接さわらない） |
| `build_artifact.py` | `_body.html` + `map.css` + `map.js` → 上の2つ |

```bash
python3 build_artifact.py   # 直したら必ず実行する
```

丸を足したり言葉を変えたりするときは、`map.js` の先頭にある `NODES` と `LINKS` を直す。
`r` が丸の大きさ、`cat` が色の種類、`body` が押したときに出る文、`post: true` を付けた丸だけ
投稿文が作られる。

## 動きの中身

- **力学** … 丸どうしが押し合い、線でつながった丸は引き合う。落ち着いたら止まる（電池のため）
- **札** … 大きい丸から順に、他の札や丸に重ならない場所を探して置く。置けなければ出さない。
  選んだ丸と真ん中の丸だけは必ず出す
- **選ぶ** … 押した丸とその隣だけ明るく残り、線が色づく。何もない所を押すと戻る
- 外部のライブラリは読み込んでいない（通信が塞がれている場所でも動く）
- 動きを減らす設定の端末では、animation を回さず最初から落ち着いた形で出す

## SNS発信について

発信の出口は会社のFacebookページ。
`map.js` の先頭の `FB_URL` に入っている。

いまの流れは **丸を押す → 投稿文ができる → コピーしてFacebookを開く → 貼る**。
`コピーだけ` を押せば開かずにコピーだけできる。文字数は数えて出していて、
140を超えるとオレンジになる（Facebookはこの長さでも問題ないが、Xにも出すなら140まで）。

押すだけで発信されるようにするには Facebook の投稿APIとアクセストークンが要る。
このページはサーバーを持たない1枚ものなので、トークンを埋め込むと誰でも読めてしまう。
つなぐなら、トークンを預かる置き場を別に用意して、そこ経由で投げる形になる。
差し込み口は `postText()` が作った文を送るところ。

## 元にした情報

- 新サイトの文言確認用プレビュー（トップ・事業内容・会社概要・お知らせ・お問い合わせ）
- Facebookページのアドレス

つまり **会社のことしか入っていない**。本人については何も聞いていないので、
勝手に埋めず、空の丸として形だけ置いてある。

オレンジの点線の丸（`cat: 'blank'`）が、その「まだ埋まっていない」印。待っているものは2種類ある。

| 丸 | 待っているもの |
| --- | --- |
| 仕事のほかに時間を使っていること／いま気になっていること | 本人に聞くこと |
| 誰に届けるか／どんな形で届けるか／いまの4事業のどれを使うか | こども教育の中身を決めること |
| 取引先の顔ぶれ／継続とスポットの割合／忙しくなる月／事業ごとの実際の大きさ | 請求書 |

「これから」（`cat: 'next'`、金色）は、やりたいと出ているがまだ始まっていないもの。
いまは **こども（幼児）教育** が入っている。始まったら `cat` を `biz` に移す。

どちらを待っているかは、丸ごとの `waiting` に書いてある。中身が入ったら `cat` を
`blank` から変えて、`body` を書き、必要なら下に丸を足す。

## アプリ一覧には入れていない

ここは PWA ではなく、ただの1枚のページ。manifest も Service Worker も置いていないので、
他のアプリの担当範囲を横取りすることはない。トップの一覧（`../index.html`）はスマホに
入れて使うアプリのための場所なので、このページは載せていない。
