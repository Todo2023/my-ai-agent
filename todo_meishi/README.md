# オンライン名刺（辰巳彩香｜合同会社To do）

紙の名刺を渡す代わりに、URLひとつを渡すためのページ。

**https://todo2023.github.io/my-ai-agent/todo_meishi/**

## 中身

| | |
| --- | --- |
| `_body.html` | 本文。**直すのはここだけ** |
| `card.css` | 見た目。色は `:root` の変数にまとめてある |
| `card.js` | 「連絡先に追加する」（vCard を渡すところ） |
| `index.html` | 公開用（自動生成。直接さわらない） |
| `artifact.html` | Artifact 用の1枚版（自動生成。直接さわらない） |
| `build.py` | `_body.html` → 上の2つ。QRもここで作って本文に埋め込む |

```bash
pip install segno      # QR に使う
python3 build.py       # 直したら必ず実行する
```

## できること

- **電話する／メールする** … `tel:` と `mailto:`。スマホならそのまま発信できる
- **連絡先に追加する** … vCard（.vcf）を渡す。電話帳にそのまま入る
- **Facebookを見る** … 会社のページへ
- **QR** … このページ自身のQR。相手のスマホで読み取ってもらえば渡せる

QRは外のファイルではなく本文に SVG として埋め込んである。画像の読み込みが
塞がれている場所でも出るようにするため。

## vCard について

Artifact の中では、ページから始めたファイル保存が止められる。そのため
`card.js` は、用意されている保存の口（`window.claude.downloads`）があれば
そちらを使い、無ければふつうのダウンロードに落とす。**公開URLのほうが本番**で、
そちらでは何もしなくても電話帳に入る。

## まだ入れていないもの

- **肩書き** … 代表社員なのか、別の書き方をするのかを伺っていないので入れていない
- **名前のローマ字** … 読み方を確認していないため。名刺で読み違えると困るので空けてある
- **顔写真・ロゴ** … 画像をもらえれば入る

## アプリ一覧には入れていない

PWA ではなく、ただの1枚のページ。manifest も Service Worker も置いていない。
