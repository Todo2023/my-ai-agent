# Ciao Hallo 設計メモ

イタリア語とオランダ語の旅行会話を1つにまとめた学習アプリ。旅行当日にこのアプリだけで完結させる。
旅行日: 2026/11/9〜11/13。利用者は両言語とも完全な初心者（日本語話者）。

> このディレクトリはカリキュラム（invoice_agent など）とは独立した個人用アプリ。LLMは使っていない。

## 現在の実装
- 単一ファイル `ciao-hallo.html`（HTML/CSS/JS、外部依存はGoogle Fontsのみ）。ブラウザで開くだけで動く
- 保存先: `localStorage`（キー `ciao-hallo-v2`）。共有はJSONファイルの書き出し・読み込み
- 公開: Claude のアーティファクト（`downloads` 機能のみ使用。使えない環境では文字列コピーに切り替わる）

## 画面（下部タブ5つ）
| タブ | 内容 |
|---|---|
| フレーズ | 13カテゴリ・164フレーズ。検索、★お気に入り、「覚えた」、聞く／ゆっくり、「見せる」（現地の人に見せる全画面表示）、発音と現地のヒント |
| カード | フラッシュカード。日→外／外→日。「まだ」は4枚後に再出題。範囲はカテゴリ／お気に入り／未習得 |
| クイズ | 4択。日→外、外→日、音声→意味の3形式。5/10/20問。結果で間違い一覧 |
| ルート | 現地時間（ローマ・アムステルダム・日本）、5日分の観光ルート、人気スポット追加、Googleマップ連携、書き出し・読み込み |
| 記録 | 習得率、連続学習日数、カテゴリ別進捗、苦手フレーズ、クイズ成績、共有、リセット |

ヘッダー: 言語切替、出発までの日数、現地時間と日本時間（20秒ごと更新）、国旗の帯。
アクセント色は言語連動（イタリア=緑、オランダ=橙）。ライト／ダーク両対応。

## データ設計
フレーズ1件 = `[id, 日本語, 伊, 伊カナ, 蘭, 蘭カナ, 伊メモ, 蘭メモ]`
- `id` の先頭1文字がカテゴリ（g あいさつ / e 必須 / n 数字 / m お金 / r レストラン / s 買い物 / t 交通 / h ホテル / d 道案内 / x 緊急 / v 観光 / a 空港 / c 時間）。学習進捗のキーなので、既存idの変更・再利用は禁止。追加は末尾の連番で。
- 状態 `S`: lang, fav{it,nl}, box{it,nl}（習得段階0〜3）, miss{it,nl}, quiz{n,ok}, days[], route{日付:[停留所]}
- 停留所: {t:"HH:MM", name, q:"地図検索用の現地表記", note, l:"it"|"nl"}
- 習得段階: 初回で覚えた→2、以後+1で3（習得済み）。間違い・「まだ」は1に戻る。習得済みで「覚えた」を押すと0に戻す

## 共有（夫婦で使う）
- 「書き出す」でJSON（ルートとお気に入りのみ）→相手が「読み込む」。同じ予定（時刻＋名前が同じ）は重複しない。習得状況は個人のため共有しない
- 次の段階の候補: `db` 機能でルートを2人で同時編集。習得状況は個人ごとに保存

## 地図・時間
- 地図は埋め込めない（iframe不可）ため、Googleマップへのリンクで開く。1日の順路は maps/dir のURLに経由地を並べて生成（徒歩モード）
- 時刻は Intl.DateTimeFormat のタイムゾーン（Europe/Rome、Europe/Amsterdam、Asia/Tokyo）。夏時間は自動。11月の時差は日本−8時間
