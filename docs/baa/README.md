# いないいないばあ

画面のどこでもさわると、手がひらいて誰かが「ばあ！」と出てくる。
**出ている顔をさわると、くすぐったがって笑う。** 顔の外をさわると隠れる。
**まちがいも、終わりも、点数もない。** 0〜2歳向け。

| ボタン | どこ | 何 |
| --- | --- | --- |
| 🥁 / 🙈 | 左上 | **おとモード**。ボタンをたたくと、その子が大きく出て**鳴いて、曲に合わせて歩く**（3〜5秒） |
| 🐾 | 右下 | **みつけた**。会った子が色つきになる。会っていない子は影 |
| ♪ / × | 右上 | 音の入切。**長押し（0.7秒）**。軽く触っただけでは変わらない |

どのボタンも小さくして端に置いてある。**切り替えるのは大人**という想定。

- 通信は一切しない。絵はその場で SVG を組み立て、音は Web Audio で作っている
- 外部の読み込みなし（CDN・画像・フォントなし）。費用ゼロ
- 出てくるのは9人。いぬ・ねこ・ぶた・くま・ねずみ・ちょうちょ・さる・ひつじ・かえる。
  ねこ と ねずみ にはひげがある。
  **おとモードが9マスなので、9人ちょうど**（8人だと1人が2回出て、犬が2匹になる）。
  **鳴き声のある動物だけにしてある**（うさぎ・ぱんだ・まるくんは外した）。
  **全部このリポジトリで描いたもの。実在のキャラクターは使っていない**
- 「みつけた」は端末の `localStorage` にだけ残る。**どこにも送らない**
- おとモードの9音はペンタトニック。どの順に叩いても外れて聞こえない
- ボタンの色は色の輪を9等分するように選び、似た色が並ばないようにしてある
- 押していないあいだも、顔がゆっくり息をして、ときどき1枚だけ跳ねて誘う。
  たたくと、その場から輪が広がる
- おとモードでボタンを押すと、その子が**全身で**大きく出る。**文字は出さない**。
  曲のあいだ、足を振りながら画面を横切って歩き、端で向きを変えて戻ってくる
  （ちょうちょは羽をはばたかせる。いぬはしっぽを振る）
- クローズアップの背景は**9人ぶん、それぞれ違う**。画像は持たず、色と丸と三角だけで描く

| 子 | 景色 |
| --- | --- |
| いぬ | 昼の草原。お日さま・雲・花・とり・山・くさむら |
| ねこ | 夕方。空も地面もオレンジ・とり・山・おうち |
| ぶた | のうじょう。土の地面・さく・おうち・石 |
| くま | 森。木・きのこ・とり |
| ねずみ | **夜**（きらきら星に合わせて）。お月さま・またたく星・ほたる・流れ星 |
| ちょうちょ | お花ばたけ。花がいちばん多く、ちょうちょも飛ぶ |
| さる | **大きな木の下**（大きな栗の木の下で、に合わせて）。落ちている木の実 |
| ひつじ | まきば。さく・おうち・山・とり |
| かえる | 雨のいけ。雨・はすの葉・水のさざ波・にじ |
- うしろに**お友達が2人**立つ。毎回ちがう顔ぶれで、体をゆらしている
  （ちょうちょがお友達のときは羽を動かす）

**景色は歌に合わせてある。** きらきら星は夜、ちょうちょうはお花ばたけ、
大きな栗の木の下では大きな木の下、かえるの合唱は雨のいけ。

## 音いろ

のこぎり波1本だと電子音に聞こえる。**倍音を数本重ね、減衰を作って**オルゴールに
寄せてある（`INSTRUMENT`）。選べるようにしていたが、選ぶ必要がないので1つに決めた。

## 鳴き声と曲

**声はすべて自分で作っている。** 端末の読み上げ（speechSynthesis）は使っていない。
日本語の音声データが入っていない端末では何も鳴らないため。「ばあ」も笑い声も同じ作り。

**`sfx/` に音源ファイルを置けば、鳴き声はそちらが鳴る**（`sfx/README.md` に手順）。
置かなければ、下の合成音のまま。

**鳴き声は、母音を合成して作っている。** 音の高さを変えるだけでは「わんわん」に
聞こえないため、のこぎり波を帯域フィルタに通してフォルマント（母音の山）を立て、
山を動かして「わ」（う→あ）のような音にしている（`VOWELS` と `vowel()`）。
端末の読み上げは日本語の声が入っていないと何も鳴らないので、使っていない。

鳴き声のあとに曲が流れて、その子が画面を歩く。長さは**16〜18秒**。前半をもう一度くり返して伸ばしてある（`tuneSeq()`）。
きらきら星だけは6行フルで元から長いので、くり返さない。歩く速さは一定で、
曲が長いぶん往復の回数が増える。

| 子 | 曲 |
| --- | --- |
| いぬ・ねこ | 自作のみじかいメロディ |
| ひつじ | メリーさんのひつじ（アメリカ民謡） |
| ぶた | むすんでひらいて（ルソー） |
| くま | 森のくまさん（アメリカ民謡） |
| ねずみ | きらきら星（フランス民謡）※6行フル |
| ちょうちょ | ちょうちょう（ドイツ民謡） |
| さる | 大きな栗の木の下で（イギリス民謡） |
| かえる | かえるの合唱（ドイツ民謡） |

**曲と絵は合わせてある。** メリーさんのひつじはひつじ、ちょうちょうはちょうちょ。

**曲は著作権の切れたものと自作だけを使う。** たとえば「犬のおまわりさん」は
作曲者が2018年に亡くなっており、まだ著作権が生きているので入れられない。
音源ファイルは1つも持たず、その場で鳴らしている（`playTune()`）。動画も使わない。
重くて、通信のない場所に持ち出せないため。

## 幼児向けにしていること

- 当たり判定は画面ぜんぶ。指1本しか使えない前提
- 点滅させない（1秒に3回以上の明滅なし）
- 拡大・引っぱり更新・長押しメニューを止めてある
- 音が出せない端末でも遊べる。**音の有無で、絵の長さは変わらない**
  （以前は音が使えないと1.1秒で画面が戻ってしまい、故障に見えた）
- 音の入切は右上の小さい丸。子供が当てにくい位置と大きさにしてある

## 新しくしたのに変わらないとき

**`app.js` などのURLに `?v=9` を付けてある。** 付けないと、Service Worker が
ブラウザの持っている古い写しをそのまま抱え込み、直したのに古い画面が出続ける
（GitHub Pages は `Cache-Control: max-age` で10分ほど持たせるため）。実際そうなった。
**中身を変えたら、`index.html` と `sw.js` の `?v=` と `VERSION` を一緒に上げること。**

いま動いている版は、**「みつけた」（🐾）の下**に「ばん 9」と出る。ここを見れば、
古いものを掴んでいるかどうかが分かる。

## 圏外で遊ぶには

Service Worker で全ファイルを抱えるので、**一度ひらけば、あとは機内モードでも動く。**

1. 電波のあるところで一度ひらく
2. ブラウザのメニューから「ホーム画面に追加」
3. 以降はアイコンから起動。通信は要らない

`file://` で直接ひらくと Service Worker が動かない。必ず http で配る。

```bash
# 家の中で確かめる
cd ..            # リポジトリの直下へ
python3 -m http.server 8000
# → http://localhost:8000/baa/
```

## アイコンを作り直す

```bash
python3 _make_icons.py
```

外部ライブラリは使っていない（`zlib` と `struct` だけ）。顔の色を変えたいときはこのファイルを直す。
